**不稳定测试版，仅供自愿体验与反馈。只支持新目录全新安装，不推送至 APP 自动更新渠道。**

本版本不是正式稳定版。未完成完整产品回归、旧数据库升级及自动更新链路验收，
可能存在功能缺陷和兼容性问题。请保留现有安装及原始课程备份。

## 下载与全新安装

1. 下载附件 `ClassroomVideoStudy-0.2.3-windows-x64.zip`。
   GitHub 自动生成的 `Source code` 附件是源码，不能替代该软件包。
2. 正常退出旧应用，将软件包完整解压到一个新的、可写的独立目录。
3. 双击 `启动课堂重点复习.cmd`，等待首次环境准备完成。
4. 重新配置 AI 服务、按需下载 ASR 模型，再导入课程。

支持 Windows 10/11 x64，需要 WebView2 Runtime。包内已包含前端，使用 APP 不要求
Node.js；首次启动仍需联网准备 Python 和锁定依赖，模型也需要另行下载。

不要覆盖旧安装，不复制旧数据库、配置、`.runtime` 或模型缓存，
不将新应用绑定到旧安装的外置数据目录。请勿同时运行新旧应用处理同一份资料。

## 本次体验内容

- 学习资料导入、手动选题，以及从题目或讲解片段打开 Codex 讨论。
- 视频副视角、时间偏移和自动对齐。
- PPT 提取、页面精选与 PDF 导出，可选独立 GPU 环境。
- 书签、续看、题目标记，以及视频库操作的撤销与重做。
- 本地字幕字面、同音候选与可选的语义检索。
- USB 课程交换、学习修改同步和缓存维护。

以上是功能范围，不代表各类设备、课程和服务商组合均已完成验收。
自动识别、配图和检索结果需要结合原始资料核对。

## 可选的 Codex 配套

软件包内的 `integrations/codex-desktop/` 包含 ClassCue 课程 MCP、讨论配套及本机安装器，
插件版本为 `0.13.0`。插件与 APP 分别安装，使用插件需要 Codex Desktop 和 Node.js 24。

也可按仓库中的 `docs/features/codex-plugin-install.md` 使用 GitHub marketplace 安装。
在 APP 的“设置 → 讨论工具”中选择 Codex，保存学习工作区后再使用；
全新安装更换 APP 目录后，需要重新保存连接。
独立的 `study-recall` 讨论检索 MCP 不包含在本次软件包中。
