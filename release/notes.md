# 0.2.1

## 下载与启动

- 下载 `ClassroomVideoStudy-0.2.1-windows-x64.zip`，解压到可写的独立目录，双击 `启动课堂重点复习.cmd`。
- 支持 Windows 10/11 x64，内置构建后的前端，无需 Node.js。首次启动仍需联网准备 Python 和依赖，并需要 WebView2。
- 首次成功启动后自动创建桌面和开始菜单快捷方式。

## 本次更新

- 整理应用源码为 `classcue/` 包，发行包保留完整目录布局，并采用明确的发行文件清单。
- 根目录仅保留主启动入口，停止、重启入口移到 `scripts/`；本地前端开发入口和私有实验数据不随发行包分发。
- 保留签名版本检查、公告、可选下载、程序文件备份和更新恢复功能，源码目录不被自动覆盖。
- 修复 Windows 持续集成兼容性问题，补充启动入口和发行清单回归测试。

## 旧版迁移

旧版若使用不支持 `classcue/` 路径的更新校验器，不能直接自动升级到此版。请先退出旧程序并备份安装目录和数据，再使用完整新发行包；需要沿用视频库时，将新安装的数据位置指向原视频库。不要绕过签名校验，也不要让两份程序同时访问同一视频库。
