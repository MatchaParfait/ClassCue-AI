# 0.2.2

## 下载与启动

- 下载 `ClassroomVideoStudy-0.2.2-windows-x64.zip`，解压到可写的独立目录，双击 `启动课堂重点复习.cmd`。
- 支持 Windows 10/11 x64，内置构建后的前端，无需 Node.js。首次启动仍需联网准备 Python 和依赖，并需要 WebView2。
- 首次成功启动后自动创建桌面和开始菜单快捷方式。

## 本次更新

- 新增形象引导与真实页面高亮的新手准备流程，覆盖存储、字幕模型、AI 服务和常用快捷键，并适应窗口大小调整。
- 支持导出和导入可分享的复习资料，保留字幕、考点及视频匹配校验，不包含 API 密钥。
- AI 服务可按连接设置请求并发上限；已有字幕与成功分析缓存继续复用。
- 改进 Windows 服务启动、就绪检查和所属进程清理，避免端口冲突影响其他服务。
- 更新状态写入遇到 Windows 短暂文件占用时有限重试；持续失败仍明确报错，不掩盖安装故障。
- 修复 Qwen 字词对齐在音频结束边界的部分失败。
- 发行包先生成草稿并验收，再正式发布；继续保留签名更新、安装确认和升级备份。

## 旧版迁移

使用未修改的 `v0.2.1` 正式便携包时，可在“设置 → 关于与更新”检查并下载新版，下载校验完成后点击“安装并重启”。开启自动下载时仍需手动确认安装；请先完成或停止运行及暂停的任务。升级保留视频、模型、配置、字幕和复习记录，并创建程序及数据库备份。

源码运行不执行原地更新。更早版本、程序文件被修改或提示不兼容时，请先正常退出并备份程序和数据，再按发行维护指南手动升级；不要绕过签名或路径校验，也不要同时运行两份程序访问同一视频库。
