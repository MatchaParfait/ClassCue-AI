# 题目讲解区间规则 v2

## 提取目标

提取教师正在处理某一道具体题目、例题、练习、试题或题图的连续讲解区间。
结果用于在该区间及其附近查找 PPT 图片，因此重点是时间范围完整、边界稳定和证据可核对，
不是把题目文字整理成最终题库条目。

## 纳入标准

1. 教师明确引入或指向具体题目，例如“来看一道题”“下面做个例题”“这道题要求……”
   “题目给出……”“我们来解这个问题”，并且字幕中能找到题目的条件、求解目标、
   选项、计算对象或具体解题动作中的至少一项。
2. 没有明确说“题目”或“例题”，但连续字幕已经给出具体条件和求解目标，
   或教师正在对一个明确实例进行列式、计算、证明、判断、作图、选择或讲解答案，也可以纳入。
3. 区间从最早能确认该题目的条件、题干或引入语句开始，覆盖教师围绕该题目的主要讲解，
   到最后一个仍属于该题目的步骤、结论、答案解释或纠错提醒结束。
4. 同一道题在本次字幕内只输出一次；不要因为教师在题目中间短暂停顿就拆开。
   题目跨块时，只标出本次实际提供的部分，不猜测其他块的编号。
5. 题目尚未讲完但已经有明确具体题目证据时，可以保留当前已确认的区间；
   不得虚构尚未出现的条件、步骤或答案。
6. 一段字幕中包含多个互不相同的题目时分别输出；同一道题的不同步骤只输出一次。
7. `title` 使用字幕支持的简短标签，优先写题型、知识点和求解对象，
   例如“二分查找边界判断例题”“带参数函数单调性题”。不要编造完整题干。
8. `evidence_sentence_ids` 只选最能证明具体题目存在或正在讲解的 1 至 3 条字幕编号，
   优先选择题目引入、具体条件、求解目标或明确解题动作；不必覆盖全部解题步骤。

## 排除标准

1. 只讲定义、定理、公式、一般方法、知识点总结或抽象题型，没有具体实例条件或求解目标时，不纳入。
2. 只说“这种题要注意”“这类题常见”或“考试可能会考”，但没有正在处理的具体题目时，不纳入。
3. 只提到“上一题”“那道题”“答案如下”等，当前字幕没有足够上下文确认具体题目时，不纳入。
4. 仅举一个孤立数字、变量、公式或计算结果，无法确认它属于具体题目时，不纳入。
5. 题目讲解结束后的闲聊、下一主题引入和与题目无关的普通知识说明不纳入。
6. 不因为教师说“重点”“关键”“容易错”就自动纳入；必须同时能定位到具体题目或具体实例。
7. 不根据学科常识补全题干，不把 PPT 可能显示的内容当作已经说出的字幕证据。

## 区间与证据

字幕以“{编号} 原文”逐行提供，每段可能由多条原始 ASR 短片段合并而成。
编号按全视频递增；本次输入可以从任意编号开始，也可能有缺口。
只使用本次实际字幕行首的整数编号，不返回时间戳，不猜测缺失编号。
`start_sentence_id` 和 `end_sentence_id` 必须覆盖题目讲解所需的最小连续范围，
不能跨越本次未提供的字幕缺口。
`evidence_sentence_ids` 按时间顺序填写，不重复，必须属于起止范围。
只返回编号，不复制、改写或拼接证据原文；程序会根据编号读取字幕原文和时间戳。
同一道题如果前后重复提及，优先保留能够覆盖题目条件和主要讲解的完整范围。

## 输出格式

只返回下列 JSON 对象，不添加额外字段、Markdown 代码块或解释文字。
没有符合规则的题目讲解区间时返回 `{"candidates":[]}`。

```json
{
  "candidates": [
    {
      "start_sentence_id": 12,
      "end_sentence_id": 14,
      "evidence_sentence_ids": [12, 14],
      "title": "题型或题目内容的简短标签"
    }
  ]
}
```

每个候选只包含上述四个字段。所有句编号必须是本次实际字幕中的整数；
`evidence_sentence_ids` 必须包含 1 至 3 个编号，按时间顺序排列且不重复；
`title` 必须非空。不返回理由、分类、证据原文或时间戳。
