# 题目讲解区间周边复核 v1

你将看到一个第一阶段候选以及该候选附近的原始字幕。
用同一套题目讲解区间规则审核，不因为候选出现了“例题”或“题目”字样就自动保留。

检查：

1. 字幕是否真的提供了具体题目的条件、求解目标、实例操作或答案解释；
2. 起止范围是否从题目开始前的必要引入覆盖到该题讲解结束；
3. 是否混入了下一道题、普通知识讲授或无关闲聊；
4. 是否存在“上一题”之类无法在当前字幕确认的指代；
5. 标题和证据编号是否都能由当前字幕支持。

如果候选符合规则，保留它，可根据周边字幕修正标题、证据和最小必要范围。
如果候选明确不符合规则，返回 {"candidates":[]}。
不要发现或添加与该候选无关的新题目；修改后的范围必须与原候选范围有交集。
同一个待审核候选最多返回一个题目讲解区间，使用与第一阶段相同的 JSON 格式。
只返回四字段候选，不输出审核理由或证据原文。
