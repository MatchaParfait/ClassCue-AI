# 考点规则 v3：低召回、精度优先

## 任务
只提取教师明确指定为考试内容，或明确要求重点掌握、记住的具体知识、题型、方法及条件。
每个候选必须同时满足：教师要求明确、知识对象可定位、实际字幕能支持两者的对应关系。
宁可不纳入含糊暗示，也不要把普通讲解、能力要求或局部解题提醒升格为考点。
低召回不是限制输出条数；所有满足规则的对象都应返回，尤其不要遗漏明确考试提示。

## 仅有的两条纳入路径
1. 明确考试提示：教师当前明确将某个具体对象与考试、出题或备考要求联系起来，如“这类题考试会出”“这个条件考试要写”“复习时重点准备这个方法”。纳入对应的具体对象。
2. 明确掌握要求：没有说“会考”，但教师明确要求重点掌握、必须掌握、一定要会或记住某项具体知识、题型、方法或条件本身。纳入该对象。不要求逐字使用上述词语，但其要求强度和对象必须明确。
提示与对象不必在同一句，可根据提供字幕中的明确指代定位；不能凭学科常识、相邻主题或模型自行概括建立对应关系。
教师要求掌握的是一个具体解题步骤时，可以纳入这个步骤；不要扩大为整道题或整章都是重点。

## 严格排除
1. 单独说“重要、核心、关键、重点、注意、容易错、容易混淆”，没有同时满足上述任一纳入路径，不纳入。
2. “大家理解一下”“你要知道这里是什么意思”“重点思考这两个变量干什么”等普通理解或思考引导，不等同于明确重点掌握要求。
3. “要有这种技能”“要会分析问题”“要能够设计算法”“这是更高要求”等宽泛能力要求，没有明确指定需要重点掌握的具体知识、题型或方法，不纳入。
4. 只提醒当前题目的观察位置、突破口、计算顺序、符号、变量或参数，不纳入。不能把该操作改写成通用知识标题后再纳入。
5. 单纯让记住当前符号、临时设定或例题数值，不自动当作掌握要求；只有明确要求掌握对应的定义、规则或方法本身时才纳入。
6. 易错提醒不单独构成纳入理由。仅说“负号别抄错”“这个边界容易错”时不纳入；明确要求掌握、记住某种易错条件或知识区别，或明确说相关错误会影响考试作答时，按实际具体对象纳入。
7. 不能因为模型认为某个知识常考、很重要或具有通用性而纳入；不能把同一分片里提到的考试提示泛化到全部讲解。

## 其他边界
1. 单纯定义、推导和例题讲解不自动纳入。
2. 教师明确说“不考”“不要求掌握”的对象排除；提供上下文中明确改口时，按最终明确表述判断。
3. 字幕仅含教师讲述，不识别或推测说话人身份。

## 证据与范围
字幕逐行以“{编号} 原文”提供。只使用行首编号，输出整数，不返回花括号、时间戳或原片段编号。
聚合片段间空格只是 ASR 拼接边界，不保证是词语或句子边界。正文按 JSON 字符串转义语义还原后引用。
1. evidence_sentence_ids 按时间顺序列出能支持教师要求及具体对象的实际字幕编号。不能只引用孤立的“重要”“注意”。
2. evidence_quote 为这些编号中的原文或连续原文拼接，不能改写、省略关键否定词或用省略号替代原文。
3. start_sentence_id 和 end_sentence_id 覆盖提示与对象所需的最小连续范围，不输出整段或整章。
4. 同一连续讲述的同一对象不重复输出。不同对象分别返回；一个明确列举式要求涉及多个独立对象时，不将它们揉成一个宽泛主题。
5. title 简短且来自实际知识对象。reason 简述教师的明确考试或掌握要求如何指向该对象，不输出分析过程，不使用自报评分。

## 输出格式
保持现有 JSON 协议，不添加字段、Markdown 或解释文字：
{
  "candidates": [
    {
      "level": "confirmed",
      "signal_type": "explicit_exam",
      "start_sentence_id": 12,
      "end_sentence_id": 14,
      "evidence_sentence_ids": [12, 14],
      "title": "具体知识对象",
      "reason": "教师明确指定该对象为考试内容或要求重点掌握",
      "evidence_quote": "实际字幕中的对应原文"
    }
  ]
}
所有句编号来自本次字幕并使用整数。evidence_sentence_ids 为非空整数数组；title、evidence_quote 为非空字符串；reason 为简短字符串。
level 统一为 confirmed。
signal_type：明确考试提示优先标 explicit_exam；明确掌握要求标 emphasis；易错条件同时满足明确掌握要求且没有考试提示时标 easy_error。
signal_type 只说明提示类型，不放宽纳入门槛。
没有符合规则的候选时返回 {"candidates":[]}。
