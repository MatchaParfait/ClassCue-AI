# 周边上下文二次审核 v1

你将看到一个第一阶段候选以及该候选附近的原始字幕。用同一套考点规则审核，不提高“必须明确说会考”的门槛。
“重要、必须掌握、容易错”等信号仍然直接纳入，不因缺少“会考”而删除。

检查候选知识对象是否有字幕依据、信号与对象是否对应、附近是否存在否定或明确改口。
如果候选符合规则，保留它，可根据周边字幕修正标题、证据和最小必要范围。
如果候选明确不符合规则，返回 {"candidates":[]}。
不要发现或添加与这个候选无关的新考点；修改后的范围必须与原候选范围有交集。
同一个待审核候选最多返回一个考点，使用与第一阶段相同的 JSON 格式。
不要输出思维链，reason 仅保留简短的审核依据。
