# 考点规则 v2：区分知识重点与局部解题提醒

## 任务与取舍
提取教师明确提示需要备考或重点掌握的具体知识、题型、方法或易错条件。
不要把“解这道题时某一步很关键”自动理解为“这道题或这个知识是考点”。
本版本优先减少此类误报。不要因此遗漏其他有充分依据的候选。

## 纳入标准
1. 教师明确说会考、必考、考试重点、考试要会等，且能定位具体知识对象时，纳入。可以是题型、方法或关键步骤，不限于整道题。
2. 没有明确考试表述，但教师把重要、重点、必须掌握、一定要会、要记住等要求直接指向某项知识、题型或方法本身时，也纳入，不要求额外出现“会考”。
3. 易错提醒只有在教师将某种知识区别、条件或方法明确作为需要记住、分清或掌握的易错点时纳入。不要求逐字出现这些词，但必须有对应的教师语义依据。
4. 先确定强调对象，再判断是否纳入。某项操作对当前题目有用，不等于教师要求将其作为重点掌握；模型认为它具有通用性，也不能代替教师的强调。
5. 纳入的候选统一使用 level="confirmed"。明确考试提示用 explicit_exam；知识或方法本身的掌握强调用 emphasis；符合第 3 条的易错提醒用 easy_error。类型不表示不同纳入等级。

## 必须排除的局部提醒
1. 仅为推进当前例题、演算、读代码或引导思考而说“重点看这里”“注意这一项”“关键是先想到这一步”“这里要先判断”“这个符号别写错”等，不直接纳入。
2. 仅强调当前题目的解题入口、突破口、观察位置、先后顺序或计算细节，没有将对应知识、题型或方法本身列为考试或掌握重点时，不纳入。
3. “注意”“关键”“重点”等词不是自动触发词。同一句中的强调可能只修饰当前操作；必须结合提供的上下文判断，不能仅靠关键词。
4. 不因为局部操作能被概括成某种知识或方法，就给它起一个通用标题并纳入。标题抽象化不能弥补教师没有表达的重点属性。
5. 只说某项能力是“更高要求”“进一步要求”或更难，没有同时表达考试、重要掌握或知识易错要求时，不仅凭要求层级纳入。
6. 如果教师在局部讲解之外明确说“这个方法必须掌握”“这种边界条件是易错点，大家要分清”或“这种步骤考试要写”，则按实际强调对象纳入。不要一律排除解题步骤，也不要把一步的提示扩大成整道题或整章的重点。

## 其他边界
1. 单纯讲授定义、推导、例题或常识，没有符合以上标准的教师提示时，不依据学科常识推断考点。
2. 教师明确说“不考”“不要求掌握”时排除相应对象；若在提供的上下文中明确改口，按最终明确表述判断。
3. 字幕全部按教师讲述处理，不需要识别或推测说话人身份。

## 证据与范围
字幕以“{编号} 原文”逐行提供，编号按全视频从 1 递增。本次提供的部分字幕可能不从 1 开始或有缺口。
只使用行首花括号中的编号，返回整数，不返回花括号、时间戳或原片段编号。
正文按 JSON 字符串内容转义（无外层双引号），引用时按 JSON 语义还原：\n 为换行，\\ 为反斜杠，\" 为双引号，\uXXXX 为对应字符。
1. 证据必须能支持教师提示与所选知识对象之间的关系，不能只有孤立的“重点”“注意”。
2. evidence_sentence_ids 列出实际证据的编号，按时间顺序排列。evidence_quote 必须为这些句子中的原文或连续原文拼接，不用省略号、不改写。
3. start_sentence_id 和 end_sentence_id 覆盖教师提示及对象所必需的最小连续范围，不把整个字幕块作为一个考点。
4. 同一连续讲述的同一对象不重复输出。不同对象即使同处一个聚合段，也可分别返回并共用编号。
5. title 为字幕支持的简短知识对象名称。reason 简述教师为什么将该对象作为考试或掌握重点；不能只写“这一解题步骤关键”。不输出分析过程。

## 输出格式
只返回下列 JSON 对象，不添加额外字段、Markdown 或解释文字。沿用原有输出协议。
句编号为来自本次字幕的整数，不用字符串、小数或布尔值；证据编号为非空整数数组。
title 和 evidence_quote 为非空字符串，reason 为简短字符串。
{
  "candidates": [
    {
      "level": "confirmed",
      "signal_type": "emphasis",
      "start_sentence_id": 12,
      "end_sentence_id": 14,
      "evidence_sentence_ids": [12, 14],
      "title": "具体知识对象",
      "reason": "教师明确要求掌握该知识或方法，而非仅提示当前解题操作",
      "evidence_quote": "实际字幕中的对应原文"
    }
  ]
}
signal_type 只允许 explicit_exam、emphasis、easy_error；无符合规则的候选时返回 {"candidates":[]}。
