# 考点规则 v1

## 纳入标准
1. 教师明确说会考、必考、考试重点、试卷会出等，纳入对应的具体知识点。
2. 教师说重要、重点、必须掌握、一定要会、要记住等，即使没有说“会考”，也直接纳入对应的具体知识点。这些是本项目认可的考点暗示，不降为普通学习重点。
3. 教师强调容易错、容易混淆、容易丢分、特别注意某个易错条件等，也直接纳入对应的具体知识点或步骤。
4. 上述候选统一使用 level="confirmed"。signal_type 分别标为 explicit_exam、emphasis 或 easy_error；它只说明教师信号类型，不表示不同纳入等级。
5. 不要求逐字命中上述词语；语义等价、且教师信号和具体对象可定位时同样纳入。

## 边界与排除
1. 单纯讲授定义、推导、例题或常识，但没有教师考试提示、强调或易错提醒，不自行推断为考点。
2. 教师明确说“这个不考”或“这个不要求掌握”时，不把该对象纳入；不把否定句里的“考”“掌握”误当正向信号。若后文明确改口，则按提供上下文中最终明确表述判断。
3. 字幕全部按教师讲述处理，不需要识别或推测说话人身份。

## 证据与范围
字幕以“{编号} 原文”逐行提供，每段可能由多条原始 ASR 短片段合并而成。
编号按全视频从 1 递增，分块、重叠、审核及格式修正不重新编号；本次仅提供部分字幕时，编号可能不从 1 开始或有缺口。
只使用行首花括号中的编号，返回整数，不返回花括号。不推测原片段编号或时间戳。
正文使用 JSON 字符串内容的转义方式（不含外层双引号），引用时按 JSON 语义还原：\n 为换行，\\ 为原文反斜杠，\" 为双引号，\uXXXX 为对应字符；转义出来的花括号不是编号。
不同知识对象即使在同一合并段内，也应分别返回，可以共用句编号。
1. 先定位体现教师信号的原句，再定位其具体知识对象或关键步骤。
2. evidence_sentence_ids 必须列出实际证据的字幕编号，按时间顺序排列；evidence_quote 必须是这些句子中的原文或连续原文拼接，不能包含省略号或改写。
3. start_sentence_id 和 end_sentence_id 覆盖信号及知识对象所必需的最小连续范围。不要把整个字幕块当一个考点，也不要只截取信号而漏掉知识对象。
4. 同一个连续讲述的考点不要重复输出；不同知识对象即使相邻，也应分别返回。
5. title 是基于字幕的简短知识对象名称，reason 简述教师信号和对象的对应关系。

## 输出格式
只返回下列 JSON 对象，字段名固定，不添加额外字段、Markdown 代码块或解释文字。
所有句编号必须来自本次提供的字幕，并使用整数，不能使用字符串、小数或布尔值。
evidence_sentence_ids 使用整数数组；title 和 evidence_quote 使用非空字符串，reason 使用字符串。
{
  "candidates": [
    {
      "level": "confirmed",
      "signal_type": "explicit_exam",
      "start_sentence_id": 12,
      "end_sentence_id": 14,
      "evidence_sentence_ids": [14],
      "title": "具体知识对象",
      "reason": "简短说明教师如何提示或强调该对象",
      "evidence_quote": "对应字幕原文"
    }
  ]
}
signal_type 只允许 explicit_exam、emphasis、easy_error；没有候选时 candidates 为 []。
