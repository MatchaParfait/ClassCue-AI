# Noto Sans SC

`NotoSansSC-Variable.ttf` is the complete, unsubsetted variable font, bundled
locally so filenames and subtitles can render without a network connection.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Original filename: `NotoSansSC[wght].ttf`
License: SIL Open Font License 1.1, included in `OFL.txt`.
UI weights: 400, 500, 600. The font retains its full variable weight axis.
