# 题目理解与字幕核验框架

## 本轮范围

本轮建立后端框架和前端接口类型，打通：

```text
既有考点 + 文字题目 / 已选 PPT 图片 + 课堂字幕与补充信息
  -> 单次图文模型分析
  -> 原题事实、推导、待明确内容、逐项核验要求
  -> 精确知识点 / 课程类别搜索
  -> 候选字幕证据核验
```

没有增加前端上传控件、PPT 选择面板或分析结果编辑界面；当前通过 API 接入。
不自动选图，不做 OCR，不联网下载图片，不修改原考点的考试置信度。
不要求 DSH、MCP 或模型自主调用工具，现有后端负责工作顺序。

## 模块与接入

| 模块 | 职责 |
| --- | --- |
| `classcue/question_analysis.py` | 输入与输出协议、图片校验、来源校验、核验目标转换 |
| `classcue/question_service.py` | 读取已选 PPT、图文请求、取消检查、保存结果 |
| `classcue/question_store.py` | 考点材料、输入快照、分析历史、结果过期 |
| `api/questions.py` | 考点级读写、启动分析任务 |
| `frontend/src/api/questions.ts` | 前端类型和请求函数，尚未加入面板 |

共享文件仅增加数据库初始化、路由注册、图文消息类型及搜索接入。
PPT 仅使用已存在的图片编号、哈希和时间字段，不依赖页面精选或 PDF 导出实现。
不读取 PPT agent 的未提交改动。

## 分析协议

模型结果的 `kind` 为 `exercise`、`topic` 或 `unclear`：

- `facts`：材料明确提供的条件、任务或主题，必须引用实际传入的来源编号。
- `knowledge_points`、`methods`：模型推导，必须引用事实编号；不能当作原题直接证据。
- `criteria`：逐项核验要求、重要性、深度及所需字幕证据，引用事实或推导编号。
- `allowed_variations`：类似题允许变化的条件；不强制另一视频使用模型建议的唯一解法。
- `unknowns`：看不清、缺失或矛盾内容。
- `keywords`：供后续搜索规划使用。

没有完整题目时可识别为考点并寻找该考点的例题；不能伪造原题。
无法建立目标时返回 `unclear`，不生成搜索目标，搜索接口要求先补充材料。
来源编号有效只能证明材料可回查，不能自动证明模型的理解正确。

转换后的目标保留原题条件、任务、建议方法、允许变化与不确定信息。
搜索模型负责生成搜索词，不能自行降低该目标的例题深度。
字幕核验继续要求候选视频自身提供条件、方法与步骤，原题事实不能替代候选字幕证据。
现有结果状态仍为覆盖、部分相关、不相关和证据不足；尚未新增两个独立的前端指标。

## API

| 请求 | 用途 |
| --- | --- |
| `GET /api/markers/{marker_id}/question` | 返回材料和最近 20 次分析，不调用模型 |
| `PUT /api/markers/{marker_id}/question` | 保存 `text` 和 `slide_ids`，不调用模型 |
| `POST /api/markers/{marker_id}/question/analyze` | 使用当前 AI 连接发起一次分析，返回分析 ID 与任务 ID |

保存示例：

```json
{"text":"请寻找演示候选键求解过程的例题。","slide_ids":[12]}
```

PPT 编号必须属于该考点的视频。最多手动选择 4 张图片，单张最多 6 MB、1600 万像素，
支持静态 JPEG、PNG、WebP；发送前验证实际格式、可解码性及内容哈希。
图片以图文消息发送到用户当前配置的模型；本地路径不发送，图片字节不写入数据库或日志。
当前只接已有 PPT 图片，独立题图上传尚未接入持久化和 API。

任务类型为 `question_analysis`，进度与取消复用 `/api/jobs`。
分析与搜索、ASR、PPT 任务共用现有互斥控制。
关闭或重启不自动恢复模型请求；收到完整且有效的结果时先保存，随后处理取消。
失败只保留可理解的错误说明，不存放供应商原始错误或无效响应。

无题目材料且无分析记录的旧考点继续沿用原有文字搜索。
存在题目材料时先分析，再调用现有 B 站规划接口；分析后可直接复用原搜索与核验接口。

## 保存与失效

SQLite 增加 `question_materials` 和 `question_analyses`。
快照包含当前考点、课堂字幕指纹、补充信息、题目文字和所选 PPT 的时间及哈希。
对应材料变化使旧分析和绑定它的 B 站搜索结果过期；不会按标题迁移。
图片发送前额外校验磁盘内容哈希；图片缺失、变化或路径越界会阻止模型请求。
读取历史时依据数据库元数据判断过期，不逐次扫描图片文件。
删除考点或视频时级联清理对应分析；PPT 图片继续由现有模块管理。
记录保存模型配置和协议版本，不保存 API Key 或 B 站凭据。
