# B 站候选截图与题型复核

## 工作流程

后端保留两条可比较路径，不改前端接入。原版使用 `question-analysis-v2`、
`bilibili-harness-v4` 和 `bilibili-visual-v1`；实验版使用
`question-analysis-v3-light`、`bilibili-harness-v5-light` 和
`bilibili-visual-v2-light`。保存考点题目材料时，可通过
`prompt_style: "structured"`（默认原版）或 `"light"` 选择；不传仍走原版。
切换仅影响新分析与新搜索，历史不覆盖，缓存按版本和图片内容隔离。

轻版只把用户选定题图与课程发给模型，直接生成简短题意、知识点和两组搜索词，
不发送课堂字幕、考点说明或旧版核验要求来约束图片理解；没有题图时才以题目文字
或考点标题作为替代。搜索规划复用这次生成的词，不再让另一个请求重写。
最终复核同时发送原题图片、候选视频截图与附近字幕，不发送旧版事实和核验清单。
模型直接回答是否类似（类似、相关、不同、不清楚）、是否有实际解题讲解、理由与引用。
轻版每次回答最多引用 20 条实际提供的字幕；这不是字幕读取或上下文的条数上限。
原版仍使用原题文字分析与候选画面，保留原来的三项独立判断。

两版均保留引用、图片归属、预算、取消和风控校验。轻版确认类似需候选图片，
确认解题讲解需候选图片和字幕；历史三维展示在轻版中由整体判断转换，
不是模型分别完成的三次独立评估，原始整体判断保存在 `comparison` 中。

搜索词生成、精确知识点检索、课程兜底、分 P 与合集目录选择继续使用现有流程。
本模块接在候选字幕读取之后，默认开启，也可以在搜索前关闭“截图复核题型”，
使用原有的纯字幕核验。当前 AI 服务必须支持图像输入；不会自动更换模型。

```text
课堂题图与考点分析
  -> 精确知识点搜索；不足时按课程与章节兜底
  -> 读取候选分 P 字幕
  -> 宽松定位可能相关的例题、运算或方法区间
  -> 打开该视频的指定分 P，在真实字幕时间附近截图
  -> 图片 + 附近字幕 + 原题分析，分别判断三个维度
  -> 必要时补拍一次，再保存有引用的结果
```

“宽松”仅适用于定位：字幕没有口述完整题干、定义或全部步骤，不再直接排除。
候选题条件可以写在画面中。字母、数值和答案不同也不直接排除。
最终核验不降低证据要求，不把原题条件当作候选题的可见事实。

## 三项判断

每项独立返回“已确认、部分符合、不符合、证据不足”，附理由和来源：

| 维度 | 判断内容 | 正向确认的证据要求 |
| --- | --- | --- |
| 同知识点 | 核心概念与方法是否相关 | 必须引用已提供的图片或字幕 |
| 类似题型 | 条件结构、适用前提、求解目标是否类似 | 必须引用可辨认的候选题图 |
| 解题讲解 | 是否实际推理、计算或应用方法 | 必须同时引用候选图片与讲解字幕 |

例题目标只有三项全部确认才成为“覆盖目标考点”的推荐。
概念目标要求同知识点与讲解两项确认。其余仍按证据保存为部分相关、不相关或证据不足。
截图只能证明该时刻的可见内容，不能证明看过全片；也不标记“原题匹配”。
后端校验图片与字幕编号，时间和跳转链接由真实记录生成，不接受模型生成的时间或链接。
编号合法并不自动保证模型语义判断正确，仍可通过截图和字幕人工核查。

## 范围与额度

- 字幕复用约 300 秒、约 30 秒重叠、每块 12,000 字符的分块；单分 P 最多选取
  60,000 字符，记录已读范围与未读部分。
- 定位到优先级较高的例题或方法后可以提前停止；每个单元先复核排序最高的一个区间。
  其他区间未作视觉核验，不能因此宣称整片没有类似题。
- 每个单元先取最多三张图；模型可引用本次提供的附近字幕编号请求补拍，
  后端据此定位，最多再取两张，只补拍一轮。
- 每次运行默认最多三个视觉单元、十五次取帧尝试；精确搜索阶段最多两个视觉单元，
  为课程兜底留出一个。最多五个字幕核验单元、每个 BV 最多三个的原限制仍保留。
- 浏览器请求独立限额为 400 次、累计 160 MiB；与原有平台 API 请求额度分开显示。
  单响应最多 32 MiB，取帧单次硬超时 60 秒。浏览器播放可能读取短暂媒体片段，
  不保存整段视频或音频文件。
- 图片在内部文本额度中每张加计 4,096 的预算估算；它不是服务商实际 token 数或费用。
  格式修复、语义引用纠正、补拍核验均计入额度，不能无限重试。

未取得清晰截图不会生成视觉成功推荐；黑屏、空白、分辨率不足或定位偏差过大的图片被拒绝。
模型不支持图像或服务失败时，已取得的截图保留，等待用户检查配置后手动继续。

## 浏览器与安全

需要本机 Microsoft Edge，以及锁定依赖中的 Playwright；不额外下载 Chromium。
取帧使用独立的无头浏览器和临时会话，不读取用户浏览器的配置或现有窗口。
默认匿名；如已在 ClassCue 扫码登录，复用 DPAPI 保存的登录会话。
登录不保证平台允许访问，认证或风控提示仍会立即暂停，需要人工处理。

仅允许 HTTPS 的 B 站页面、必要播放器 API 和媒体、脚本资源域；
限制 GET/HEAD，阻止其他域名、下载和账号互动请求。
WebSocket 路由只在本地接收并丢弃消息，不连接远端、不转发消息，
也不在路由回调中同步关闭连接，避免驱动回调阻塞整个取帧。
Cookie 仅限 B 站域，不转发至媒体 CDN，不发送给模型。
候选图片和附近字幕发送至当前 AI 服务，凭据和本地路径不进入提示词。

浏览器在独立工作进程运行；凭据只通过私有管道传入，不在进程参数、数据库或日志中保存。
请求额度需主进程确认后才能继续。超时报告保留最后一个白名单阶段，
不包含驱动原始错误。取消或超时会终止本次工作进程及其子进程，
不等待浏览器恢复，也不关闭用户的浏览器窗口。AI 请求的取消行为仍沿用连接配置。

## 持久化与界面

数据库 `bili_frames` 关联考点、视频、运行、BV、CID、分 P、请求时间、
实际截图时间、时间来源、尺寸及内容哈希；图片单独保存在视频库作用域的
`bilibili-frames/`。不把图片字节放进运行 JSON 或日志。

优先记录实际解码帧时间；播放器不提供该回调时明确标为播放器时间，不伪称逐帧精度。
每次核验前校验图片哈希，重复画面只发送一次。图片按当前运行隔离，
取消后继续复用已保存截图，不重复取帧。删除考点、运行或视频时级联登记清理。

结果区展示三项判断、引用截图、实际时间和 B 站跳转，可内联放大截图。
当前提示词协议为 `bilibili-harness-v4`、`bilibili-visual-v1`；
旧结果仍可回看，不能作为新版搜索依据，需要重新生成方案，不自动联网迁移。

接口补充：

- `POST /api/markers/{marker_id}/bilibili/search`：新增布尔字段
  `visual_verification`，默认 `true`；设为 `false` 使用纯字幕流程。
- `GET /api/markers/{marker_id}/bilibili/runs/{run_id}/frames/{frame_id}`：
  只返回属于该考点和运行的图片，不返回文件路径，禁止 HTTP 缓存。
- 进度新增 `locating`、`capturing`、`visual_checking`，取消与继续沿用现有任务接口。

## 验证边界

自动化使用合成课堂、模拟平台、假模型及被拦截的合成视频；不调用付费 AI。
覆盖定位引用、三项判定、伪造引用、截图所有权、补拍上限、黑屏、预算、取消、
超时、风控暂停、重启读取、图片清理和前端证据展示。

另做低频真实只读检查，确认单个候选视频可以在指定分 P、指定时间取得可辨认画面。
这不代表所有视频或分 P 都可读取，也不代表真实模型的题型判断质量已验收。
真实课堂、截图和实验原始记录仅保留在被忽略的本地运行目录。
