# 学习资料分享

## 第一版范围

一个 `.studyshare` 文件对应一个视频。分享包是 UTF-8 JSON，不包含视频、
音频、电脑路径、API 密钥、处理调用日志或自定义提示词，不需要服务器或账号。

分享者在视频库已完成视频的管理菜单选择“导出分享包”。接收方先导入同一份视频，
不启动处理，然后在视频库工具栏选择“导入分享包”。预览显示匹配视频、字幕、
考点数量和召回方案；确认后直接打开复习页，不创建 ASR/AI 任务。

视频匹配依据完整文件的 SHA-256，而非文件名。改名或复制不影响匹配，转码、
压缩或修改容器元数据后不再匹配。预览和确认都重新读取本地文件进行校验。

## 数据约定

- `format: classroom-study-share`，`version: 1`，扩展名 `.studyshare`。
- 最大 32 MiB，单视频最长 60 分钟、最大 1 GiB，与视频导入上限一致。
- `video` 仅含哈希、分享名称、文件大小、时长。
- `subtitles` 包含字幕编号、毫秒时间、文本、已有的秒制逐字时间与概率。
- `markers` 包含标题、说明、原文、原始时间、手动跳转时间、重要程度及方案归属。
- 只导出已完成方案的有效考点，不导出已移除考点；掌握/已看状态不跨用户传递。
- `analysis_runs` 保存完成方案，包括零考点方案；导入后的状态为 `completed`。
- 自定义方案仅分享结果和名称。导入时分配新的 `custom_` ID，以停用的历史方案
  保存标签，不带入可执行提示词、不占启用方案名额，也不覆盖本机的同名方案。
- 不导入分享者的内部数据库 ID、分析签名或实验 ID。

分享包不含数字签名；视频哈希只证明匹配的视频文件，不证明分享者身份、
字幕或考点的真实性。应仅导入可信来源的资料。

## 接口与一致性

- `GET /api/videos/{id}/study-share`：校验视频后下载分享包。
- `POST /api/study-shares/preview`：以原始文件字节请求，完整校验后返回预览。
- `POST /api/study-shares/import?package_hash=...&video_id=...&library_id=...`：
  再次提交同一文件，固定预览的视频库、视频及规范化分享包摘要。

预览不写入数据库。确认时重新检查视频库身份、媒体内容、任务占用和已有数据。
正在运行、排队或资源暂停的单视频及整个批次队列受保护，目录迁移全局互斥；
无关视频的任务不影响导入。

只允许向没有字幕、考点或分析记录的视频导入，不提供覆盖操作。字幕、考点、
自定义历史标签、完成状态和导入凭据在同一事务中提交。重复导入同一分享包
只返回已有视频，不覆盖之后的人工调整。转写重置、源内容替换时清除凭据；
删除及回收站恢复一并保留凭据。

分享包经过严格的字段白名单、版本、长度、时间范围、唯一性和方案关联校验。
时间规则沿用现有处理与编辑逻辑：允许字幕的 1 毫秒舍入尾差、零时长字幕，
以及恰好位于视频结尾的手动跳转位置，不重写分享者的时间。
作为纯数据解析，不解压文件，不执行脚本，不根据包中字段访问路径或网络。

## 界面设计

采用现有产品扩展模式，保留视频库、导航、处理和复习布局，以及新手指导。
面向桌面近距离使用，导入弹窗负责预览和确认，不增加独立分享管理页。

设计参数：视觉变化 2/10，动效 3/10，信息密度 7/10，图片依赖 1/10，
品牌一致性 10/10。使用现有黄绿主题变量、Noto Sans SC 字体、6px 按钮、
8px 弹窗圆角、既有阴影和短过渡，复用焦点圈、Esc 关闭及焦点恢复。
确认写入期间禁止重复操作和关闭，失败保留文件并要求重新校验。

## 验证

```powershell
.venv/Scripts/python.exe -m pytest tests/test_study_share.py -q
cd frontend
npm test
npm run build
```

本机 Node 26 在 jsdom 测试中需要设置
`NODE_OPTIONS=--no-experimental-webstorage`，使用 jsdom 的浏览器存储实现。
此设置仅用于运行测试，不修改应用行为。

`node tests/frontend_study_share.cjs` 使用临时数据库、生成的视频及本地分享包，
检查四档桌面宽度、预览、失败重试、直接复习、重复导入和下载。
所有 ASR/AI 任务在测试中禁止提交。
