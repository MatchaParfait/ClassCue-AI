# B 站真实链路测试清单

编写日期：2026-10-23。

状态：本文件以待执行清单为主，末节单独记录已经完成的真实检查；未记录为通过的
项目仍为待测。已有模拟测试结果见
[交付核查](bilibili-harness-validation.md)，不得视为下列实测已通过。

## 一、测试目标

优先回答以下问题：

1. 正式客户端能否取得真实视频详情、分 P 标题、页码和对应 CID？
2. 能否打开非首 P 的网页，并确认页面内容与选中的章节一致？
3. 能否取得这个分 P 自身的字幕，尤其是 B 站自动字幕，而不是误读 P1？
4. 字幕内容、时间范围和证据跳转链接能否与实际播放对应？
5. 上述链路通畅后，真实 LLM 能否区分例题应用、只有概念介绍和不相关内容？

接口读取成功、网页打开成功和模型判断正确是三个独立结论，分别记录。
当前产品通过接口读取字幕，不需要浏览器点击分 P 才能取字幕；打开网页是人工
核对章节和时间点的验收步骤，不把它描述成后端自动浏览视频。

## 二、环境和执行约束

- 使用独立测试视频库、配置目录、平台缓存和空闲服务端口，不操作真实课堂库。
- 课堂考点及字幕使用合成材料；B 站样本使用用户指定或确认的公开视频。
- 使用当前正式 `BilibiliClient`，保留其请求头、WBI 签名、Cookie 域名限制及风控暂停。
  不用裸 HTTP 请求的结果代替正式客户端测试结果。
- 确认预览是否替换了 `BilibiliClient` 或 `StudyModel`。模拟预览不能用于宣称真实
  读取成功；真实平台加假模型只能验证检索控制流程，不能验证模型判断效果。
- 匿名与登录态使用分开的测试缓存，记录请求是否命中缓存。每个链路的首个
  成功结论必须来自本轮实际平台响应，而不是旧缓存。
- 先不调用模型，依次验证详情、字幕和搜索；取得可核查字幕后才进入模型阶段。
- 扫码和手机确认由用户完成，不索取账号密码，不扫描浏览器或把 Cookie 发到聊天。
  用户在 B 站网页已登录，不代表 ClassCue 已登录，反过来也一样。
- 本轮是手动、低频的只读可用性核查，不并发、不循环重试、不触发点赞等账号互动。
  读取测试的主动请求串行间隔至少 3 秒；这是本轮节奏约定，不是避免风控的保证。
- 首轮平台接口及字幕资源请求累计最多 15 次，包含 WBI 导航请求等依赖请求；
  达到后汇报阶段结果。浏览器正常页面资源另计，不自动反复刷新。
- 扫码生成和轮询另行记录，遵循当前实现的最小轮询间隔；最多人工发起一轮，
  失败、取消或过期即停止，不自动刷新二维码。
- 遇到验证码、认证失效或风控立即停止后续主动平台请求。不要为了完成对照，
  继续切换登录态探测；用户检查并明确恢复后另起一轮，不清除暂停绕过限制。
- 原始响应、字幕、截图和日志只保留在已忽略的 `.runtime/`。
  文档仅记录脱敏结论，不写 Cookie、二维码密钥、临时字幕资源地址或模型密钥。

## 三、样本准备

样本类别由测试时实际页面和接口确认，不能根据标题预先假定有分 P 或有字幕。
同一个视频可以承担多个测试角色，但普通视频、多 P、跨 BV 合集必须分清。

| 编号 | 所需样本 | 用途 | 初始状态 |
| --- | --- | --- | --- |
| S1 | 用户提供的 `BV1Ae9dYqEHq` | 核对课程目录究竟属于分 P、合集或两者并存 | 待确认结构与字幕 |
| S2 | 有至少两个分 P，且非首 P 有可用字幕的视频 | 验证 P1/Pn 的标题、CID、字幕不串页 | 待选 |
| S3 | 有中文字幕的普通单视频 | 验证不依赖分 P 的读取路径 | 待选 |
| S4 | 网页可核查的中文自动字幕轨 | 确认能读取平台自动字幕及来源标记 | 待选，可与 S2 重合 |
| S5 | 人工字幕或同时存在多种语言字幕的视频 | 验证语言、人工/自动选择 | 后续补充 |
| S6 | 确实无字幕、或明确提示登录后可读的章节 | 验证缺证据和权限状态 | 后续补充 |
| S7 | 有关联合集，目标章节位于另一 BV | 验证跨 BV 课程目录 | 可由 S1 承担，待确认 |

选择 S2 时优先使用内容明显不同的两个章节，例如概述与 SQL；
至少选一个 `p > 1` 的章节。若首个样本不符合条件，记录不适用并选替代样本，
不能把“没碰到这种样本”记成通过。

## 四、第一轮：只测目录和字幕

本轮不调用真实 LLM，也不启动会自动搜索和核验全部候选的完整任务。
以生产读取模块执行单步检查，便于定位错误发生在哪一层。

| 编号 | 实际操作 | 通过标准 |
| --- | --- | --- |
| A01 | 检查启动配置、正式客户端和隔离缓存 | 未使用网络 mock；未指向真实课堂库；状态与缓存来源可区分 |
| A02 | 匿名取得一个样本的视频详情 | 获得当前视频标题及有效详情；记录 HTTP 与平台业务码 |
| A03 | 对照网页列出分 P 标题、页码、CID、时长 | 非首 P 与网页对应；不混淆合集条目；目录截断有明确标记 |
| A04 | 打开选中非首 P 的 `?p=N` 页面 | 实际播放章节和页面选中项正确，不只检查 URL 或 HTTP 200 |
| A05 | 匿名查询该 BV、CID 的字幕轨 | 记录可用、需登录、无字幕或失败；不得把空轨统一归为无字幕 |
| A06 | 必要时由用户扫码并在手机确认 | 只有有效登录凭据保存后显示已登录；不能仅以扫码成功文案判定 |
| A07 | 在用户允许且平台未暂停时，以登录态查询同一分 P | 与匿名结果分开记录；已保存登录态不等于字幕一定可读 |
| A08 | 获取该分 P 的字幕正文 | 非空文本带有效起止时间和来源；不是摘要、弹幕或画面烧录文字 |
| A09 | 对比 P1 与非首 P 的字幕 | BV、页码、CID、缓存身份正确；内容符合各自章节，不误复用 P1 |
| A10 | 核对自动字幕及人工字幕标记 | 至少实取一条可确认的中文自动字幕轨；轨道字段和网页可见信息互相核对 |
| A11 | 在一个章节抽查开头、中段、结尾附近的三处字幕 | 内容与实际语音大致对应；时间有效；记录偏差，不宣称字幕零错误 |
| A12 | 从字幕生成非首 P 的带时间跳转链接并打开 | 仍在正确分 P，跳转到引用附近；记录实际播放位置与偏差 |

A10 若选中的视频同时具备人工和自动轨，当前优先人工的行为可以通过，
但不能据此声称“自动字幕读取通过”。需要另选实际使用自动轨的样本。
视频画面上有文字也不能证明接口提供独立字幕轨。

首轮预算不足时优先完成 A02～A05 和 A08～A12 的一条最短路径；
登录对照、第二个章节或额外样本移到下一轮。任何未执行项保持待测。

### 首轮最低成功条件

- 至少一个真实多 P 视频的目录字段与网页一致。
- 至少一个非首 P 成功读取自己的字幕，且确认不是 P1 字幕。
- 至少一个样本确实使用平台自动字幕轨，而非只有人工字幕。
- 字幕引用能打开正确分 P，并经人工检查到达对应讲解附近。

只读到了详情或分 P 标题，不算字幕读取成功；只读到人工字幕，
不能替代自动字幕这一验收项。

## 五、第二轮：搜索、普通视频和课程目录

前置条件：至少已用真实客户端完成一个字幕读取闭环；本轮默认仍不调用真实 LLM。
如用假模型控制候选顺序，必须标记，不能据此评价真实语义排序。

| 编号 | 实际操作 | 通过标准 |
| --- | --- | --- |
| B01 | 用一个明确知识点词查询第一页 | 返回真实 BV、标题、简介和作者；WBI 请求有效，不要求与网页个性化排序完全相同 |
| B02 | 用另一个相关词检索，检查重复 BV | 同一 BV 合并，保留各自搜索来源；未核验候选不成为推荐 |
| B03 | 人工指定一个普通单视频读取详情和字幕 | 没有分 P 也能处理，不伪造多 P 结构 |
| B04 | 用课程类别词检索并展开一个相关课程目录 | 区分同 BV 分 P 与不同 BV 合集；记录标题及实际覆盖范围 |
| B05 | 从目录选择另一 BV 的目标章节并读取字幕 | 使用目标 BV 的实际 CID，不沿用入口视频的 CID；证据保留目录来源 |
| B06 | 若出现目录缺页或超出读取上限 | 清楚标记目录未读完，不宣称已遍历整个课程 |
| B07 | 比较匿名与登录态的相同已批准请求 | 记录各自能力和错误，不概括成“登录必然解决限制” |

无字幕、过期凭据、网络失败和风控若自然出现，就记录真实行为；不得为覆盖测试
故意制造高频请求、伪造过期凭据或诱发验证码。未自然遇到的分支继续由模拟测试覆盖。

## 六、第三轮：真实模型判断

前置条件：用户明确同意使用所选 AI 服务并确认费用预算；使用合成课堂材料和已核查
的公开视频字幕。进入本阶段前记录模型、接口配置、提示词版本、请求与估算 token
上限；不直接把默认整任务预算当作本轮费用授权。

先做单章节核验，再做一次受限完整流程。人工先看相关片段，建立参考判断：

| 编号 | 测试材料或操作 | 通过标准 |
| --- | --- | --- |
| C01 | 合成考点加课程和补充要求，生成并编辑目标/搜索词 | 来源可追溯，不编造题干；明确要求 `example`，不是概念深度 |
| C02 | 同知识点、同类方法，含实际例题的正样本 | 能引用这道例题的条件、方法和步骤；人工确认理由合理 |
| C03 | 标题相关但只介绍概念的对照样本 | 不满足“例题应用”时不能作为合格例题推荐 |
| C04 | 方法或知识点不符的对照样本 | 不因标题相似或术语出现而通过 |
| C05 | 关键条件只在画面、字幕讲述不完整的样本 | 不补造条件；证据不足时明确未知，不能声称画面或原题已确认 |
| C06 | 精确知识点搜索产生合格证据 | 返回证据与时间链接，找到一个满足核心要求的讲解就停止 |
| C07 | 精确搜索未获得合格结果，课程搜索可找到目标章节 | 正确回退并选择相关章节，再读字幕；每一步来源可见 |

C07 必须有实际失败原因及后续课程结果；若本轮精确搜索已经成功，不能为得到
回退结论而捏造失败。可另选合适目标，或保留待测。
有限正负样本通过只证明这些样本的表现，不据此宣称通用准确率。

## 七、第四轮：任务、证据和恢复

| 编号 | 实际操作 | 通过标准 |
| --- | --- | --- |
| D01 | 在查询或核验中停止任务 | 当前请求结束后的检查点停止；不继续派发新请求；已完成证据保留 |
| D02 | 刷新或重启隔离服务，查看并手动继续 | 历史仍可查；未手动继续不自动联网；完成的块不重复计费请求 |
| D03 | 本轮重复读取，再分别改变分 P、账号范围或考点 | 正确命中或隔离缓存，不能复用其他 CID 或其他账号范围的结果 |
| D04 | 核查返回的引用及跳转时间 | 引用对应已提交字幕；时间来自字幕，不来自模型自由填写 |
| D05 | 自然出现缺字幕、认证或平台限制 | 展示正确状态，暂停后不继续请求，不用标题或摘要生成替代推荐 |
| D06 | 如取得超过 60,000 字符的真实章节 | 标记实际核验范围，未读部分为未知；不要求为此扩大首轮采集 |
| D07 | 查看结果归属、更新合成考点或补充要求 | 结果绑定原考点，旧记录过期；不修改考试置信度，不标记原题匹配 |

无效引用、伪造时间、模型格式错误、极端长字幕、预算耗尽等可控故障继续做合成测试，
不通过操纵真实平台或反复付费来制造。PPT 提取和 B 站任务的互斥已有合成集成测试；
本清单不恢复全量回归。

## 九、首轮实测进展

2026-10-23，使用隔离测试库和正式 `BilibiliClient`，未使用模拟网络，
未提供登录 Cookie，未调用模型；串行执行 4 次真实平台请求。

| 检查 | 结果 | 结论边界 |
| --- | --- | --- |
| 匿名导航及 WBI 参数 | 取得签名所需参数，未登录 | 本轮匿名签名链路可用 |
| 关键词搜索第一页 | 返回 20 个候选 | 后台真实关键词取候选已通过，不等于模型排序或完整推荐通过 |
| 指定公开视频详情 | 返回 7 个分 P 的标题、页码及 CID | 接口解析成功，尚未逐一人工核对网页 |
| 非首 P 字幕 | P2 返回 `requires_login` | 匿名字幕取证受阻，不能记为取得了字幕 |

没有出现 HTTP 412，未产生风控暂停。以上结果不证明登录后一定可读字幕，
也不能替代自动字幕类型、实际内容、时间跳转、其他分 P 和真实模型核验。
下一步由用户在隔离实测服务扫码，手机确认后再进行低频登录态检查。
原始结果仅保留于本地 `.runtime/`，不加入源码或发行包。

### 用户扫码后的登录态核查

2026-10-23，用户扫码并在手机确认后，正式客户端串行执行 7 次真实平台请求，
未使用模拟网络，未调用模型，没有发生 HTTP 412 或风控暂停。
导航接口实际返回 `isLogin=true`，不只是本机凭据文件存在。

| 检查 | 本轮结果 | 状态 |
| --- | --- | --- |
| 登录有效性 | 平台确认已登录，取得 WBI 参数 | 通过 |

| 视频详情及分 P 解析 | 取得指定视频的 7 个分 P | 接口读取通过，网页逐项核对待测 |

这两项仍为待测。真实 LLM 的候选排序、例题条件与步骤判断，以及从考点出发的
完整自动推荐也仍为待测。关键词取候选成功不等于整条推荐链路验收通过。
