# Windows 桌面生命周期

桌面入口为 `scripts/desktop_launcher.vbs`（无控制台窗口），也可双击根目录 `启动课堂重点复习.cmd`。首次成功打开会安装桌面与开始菜单快捷方式，随后直接双击图标即可。当前是源码安装形态，尚未制作独立安装包或自动更新器。

## 启动与窗口

1. 准备窗口检查私有 Python、桌面依赖、内置 GTCRN 模型及前端构建；失败时提供重试与日志入口。模型和许可证随 `assets/gtcrn/` 分发，只做本地校验，无需额外下载。首次构建需要 Node.js，准备完成后的正常桌面运行不需要 Node/Vite 服务。
2. pywebview 使用 Windows WebView2 打开独立窗口，具有应用图标、标题栏和任务栏入口。页面、业务 API、ASR 工作进程与浏览器版共用同一套代码和数据。
3. 桌面模式通过 API 的同一来源提供构建后的 React 页面，支持 `/review/1`、`/process`、`/settings` 等直接路由。不存在的 API 和静态资源仍返回 404。
4. 同一安装目录通过持有整个桌面进程生命周期的文件锁实现单实例。第二次启动通过仅监听回环地址、需要随机令牌的 IPC 唤起原窗口，不重复创建模型、后端或托盘。

桌面窗口关闭与路由切换不会创建新的数据库。WebView2 的显示偏好与浏览器缓存使用安装目录下 `.runtime/webview`，后端加密凭据文件仍由原设置目录管理。

## 任务、关闭与退出

| 操作 | 行为 |
| --- | --- |
| 点击右上角关闭按钮 | 默认询问“最小化到托盘／退出应用”，焦点为“取消关闭”；可勾选“下次不再询问”记住选择 |
| 选择最小化到托盘 | 隐藏窗口，任务继续；托盘不可用时禁用该选项，已记住的托盘选择也回退为询问 |
| 选择退出应用 | 无任务时清理并退出；有任务时仍确认“停止任务并退出”，记住关闭偏好不会跳过任务保护 |
| 从托盘打开 | 唤起同一窗口，保留页面、草稿和播放器位置 |
| 从托盘退出 | 有任务时确认“停止任务并退出”，通过原取消接口等待安全停止；无任务直接清理并退出 |
| 托盘初始化失败 | 不允许隐藏成无法找回的后台实例；保持可见窗口 |
| 无法确认服务身份或任务状态 | 保留窗口，提供重新检查；不终止未核验的进程 |
| 重启 | 有任务时提示先停止；空闲时复用原启动器进行重启 |

启动器仍按进程创建时间、启动脚本、安装目录和端口验证服务归属；没有按进程名批量结束 Python、Node 或其他项目。退出前会再次检查任务，避免检查与关闭之间新增任务被强制中断。正常安全停止最长等待 180 秒，超时保留窗口供稍后重试。

## 快捷键与数据迁移

在“设置 → 快捷键”或托盘“快捷键设置…”统一配置启动／唤起、全局搜索、复习及播放器快捷键。字幕位置使用鼠标拖动，双击或播放器设置中的恢复按钮复位，不提供位置移动快捷键。支持直接按键录入、两个应用内绑定、清空停用、恢复默认及冲突校验；按钮提示同步采用新绑定。应用内绑定保存在当前浏览器／桌面窗口的本地偏好，唤起键仍写入 Windows 快捷方式。Tab、Enter、Esc 等基础键盘行为保留。

关闭窗口行为位于“设置 → 桌面设置”，可随时改回“每次询问”。原左下角混合弹窗已移除。支持 `Ctrl+Alt+字母/数字`、`Ctrl+Shift+字母/数字`，留空关闭。通过 Windows 桌面 `.lnk` 的 Hotkey 配置实现，应用完全退出后也可启动；组合键与其他应用冲突时可换一个组合。

需要手动保存的 AI 连接、ASR 模型与设备、快捷键、存储目录及导入偏好，离开页面或设置分类时统一提示“保存并离开／放弃修改／继续编辑”。保存失败保留草稿并停止跳转，放弃则恢复已保存值。应用数据目录与其他目录迁移仍先进入既有迁移确认，不能通过离开提示直接开始迁移或重启。即时保存的偏好不触发此提示。

桌面右上角关闭与托盘退出先处理未保存修改，再执行已选择的关闭行为及任务保护；记住“直接退出”也不会跳过草稿确认。网页刷新、关闭标签页或整页跳转使用浏览器原生离开警告；浏览器不允许在卸载期间使用自定义三按钮弹窗或可靠地异步保存，需要取消离开后在页面内保存。

配置写入应用设置目录的 `desktop_settings.json`，纳入应用数据迁移白名单。数据迁移仍由原来的重启辅助进程离线复制、校验、切换目录并立即重启 API；桌面宿主与窗口不被当作 API 子进程结束，页面自动重连。服务新身份必须与启动器记录一致才被接受。

根目录仅保留 `启动课堂重点复习.cmd` 主入口；辅助维护入口为 `scripts/停止课堂重点复习.cmd` 和 `scripts/重启课堂重点复习.cmd`。日常使用可通过桌面或开始菜单快捷方式打开应用，通过窗口或托盘退出。

浏览器开发入口为 `scripts/启动本地前端.cmd`，仅保留在源码仓库，不随用户发行包分发；生产桌面入口保留其已有端口与数据库。切换到桌面时若旧 API 尚不支持静态页面，会先验证空闲再重启；不会中断正在运行的任务。

## 开发与验证

正式便携包的签名更新、公告、确认安装、任务保护及程序备份见 [发行与公告](releases.md)。源码目录不被自动更新覆盖。

- 安装桌面额外依赖：`uv sync --extra desktop`。
- 手工启动：`python scripts/desktop_app.py`；`--action exit` 请求退出，`--action restart` 请求重启。
- 原生关闭与托盘行为：`tests/test_desktop_runtime.py`。
- 页面桥接、取消默认焦点与错误处理：`frontend/src/components/DesktopControls.test.tsx`。
- 原启动器、数据迁移和任务接口沿用已有回归测试。
- 原生验收可通过测试进程专用的 `CLASSROOM_DESKTOP_DEBUG_PORT` 连接 WebView2 调试端口；正常启动不开启此端口。
- 安装 Playwright 后运行 `node tests/desktop_smoke.cjs`，会在 `.runtime` 建立隔离数据进行原生验收；也可用 `CLASSROOM_PLAYWRIGHT_MODULE` 指向已有 Playwright 模块目录。
