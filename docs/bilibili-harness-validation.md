# B 站检索 Harness 交付核查

## 实现范围

- 目标卡及考点级补充信息，精确知识点搜索优先，未获得合格证据后转课程搜索。
- 找到一个满足要求的讲解即停止；普通视频、多 P 和直接关联合集分别处理。
- 独立分块提取与综合核验，检查引用、要求深度和例题连续性。
- 队列补选、第三轮补搜确认、预算预留、取消、保留预算的继续任务及重启恢复。
- 结果、字幕证据、时间链接、目录覆盖范围和运行轨迹持久化。
- 面板支持目标深度与搜索词编辑、阶段状态、候选与推荐区分、继续及预算追加。

## 尚未确认

- 此前使用未带正式客户端固定请求头的匿名请求核查公开视频详情，返回 HTTP 412 后停止。
  这不能证明正式客户端必然失败，也不能证明登录可以解决。模拟测试和合成浏览器流程
  不证明真实 B 站字幕链路或真实 AI 判断效果可用；检索回归未重新请求真实视频或模型。
- 合集只读取详情响应提供的目录；没有自动补齐未返回分页的能力，界面明确显示未读完。
- 长字幕窗口选择可能漏掉不含目标术语的例题，未处理范围保持未知。
- 引用与范围校验可保证可回查来源，不能替代人工判断模型语义是否正确。
- token 和综合请求预留采用估算，实际综合请求仍执行发送前预算检查；不足时保存已完成证据并停止。
