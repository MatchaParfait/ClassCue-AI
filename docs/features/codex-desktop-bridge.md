# Codex 桌面讨论插件

讨论流程始于 2026-11-06，当前插件版本 `0.8.0`。

ClassCue 保存课程、资料、原题快照和讨论绑定。Codex 保存独立对话及后续上下文。
所有讨论使用同一机制，不区分资料讨论和题目讨论。同一份资料可有多个独立讨论，
情景题的多个小问仍一起讨论。

## 使用流程

用户在 ClassCue 点击一次“在 Codex 中讨论”，进入绑定讨论；
首次准备讨论时，Windows 桌面桥接追加原题文字和普通图片附件，供用户检查和发送。
保留已有草稿，不自动发送消息。后续打开回到同一讨论，不重复附图；
历史加入回执不能证明当前输入框中仍有附件。

插件负责后台连接，不要求用户打开面板、领取题目、刷新或手动粘贴。
面板可作为可选的原题查看入口，不是正常发起讨论的前置步骤。

`0.3.0` 将触发路径改到讨论按钮，面板改为只读。旧版面板的实测结果不能作为
新路径的桌面验收。新路径的自动化测试通过后，仍需单独确认实际桌面的
普通图片缩略图、已有草稿保留、同一讨论重开与不重复附图。

## 可选的原题面板

1. 在 ClassCue 题目旁点击“在 Codex 中讨论”，打开已绑定的对话。
2. 在该对话的右侧面板点击“＋ → 更多工具…”，在“插件和 MCP”中选择
   “ClassCue 题目”。这是面板的新标签页入口，
   不是输入框的附件按钮。如果更新后列表没有该项，先完全退出并重新启动 Codex。
   面板按来源顺序显示原题和题图，打开或刷新均不会加入草稿。
3. 查看完成后可关闭面板；正常发起讨论不需要以上操作。

原生附图由 Windows 粘贴路径完成，不再将图片作为 MCP“上下文”附件传入。
不改写 Codex 私有数据库，不发送模型消息。

## 目录与身份

在“设置 → 讨论工具”中选择 Codex，再选择一次默认工作区。磁盘按需建立：

```text
ClassCue-AI-Codex/
  .classcue-codex/drafts.sqlite
  数据库-短标识/
    试卷1-短标识/
      .classcue/discussions/讨论编号/context.json
    试卷2-短标识/
```

短标识区分同名课程和资料。讨论按资料 ID、题目 ID、内容版本、原生线程 ID 绑定，
不根据标题猜测。对话工作目录是资料目录；快照不是聊天历史副本。
改名不会改绑，题目改版需明确新建讨论，旧版本仍可打开。
更换默认目录不会迁移已有资料及讨论。

Codex 通过 `threadSection/create` 和 `thread/section/move` 建立课程分组，
试卷名作为对话标题的一部分。侧栏组内平铺，磁盘保留课程、试卷两层目录。
外部删除原分组或对话时报告缺失，不静默创建替代项。

## 安装

推荐使用同仓库 marketplace，见[可选配套安装与更新](codex-plugin-install.md)。
本节保留个人来源的本机安装器，方便已有安装继续更新。
需要 Windows、Codex CLI、Node.js 24 及以上、PowerShell 7。
先创建学习工作区，然后执行：

```powershell
pwsh -File integrations/codex-desktop/install.ps1 -WorkspaceRoot '<学习工作区>'
```

安装器复制插件源码及预构建运行文件，合并个人 marketplace 中的 ClassCue 条目，
保留其他插件。安装后的绝对路径只保留在本机，不覆盖回源码。
重启 Codex，在个人插件来源安装或更新 ClassCue。CLI 也可执行：

```powershell
codex plugin marketplace add '<用户主目录>'
codex plugin add classcue@personal
```

在 ClassCue 的“讨论工具”设置中选择 Codex，并选择相同学习工作区。默认讨论工具可切回 DSH，
两端历史独立保存，不自动迁移旧聊天。
安装器在所选 Codex 数据目录的 `classcue/connection.json` 登记读取范围。
ClassCue 保存新工作区和重新打开旧讨论时，自动同步该连接文件；
插件逐次读取，不再将启动时的目录固定为唯一读取位置。
原工作区仍保留，用原生线程 ID 找到对应快照，不按最后使用的资料猜测。
从旧版升级到 `0.3.0` 后，插件面板变为只读；原生附图由更新后的 ClassCue 执行，
不依赖面板加载。更新面板版本需重启 Codex，后续切换工作区无需反复安装插件。

## 草稿与回执

桥接通过 App Server 创建并命名持久线程，再打开 `codex://threads/<线程 ID>`。
新讨论不再用 `thread/inject_items` 隐藏注入原题，也不调用 `turn/start`。
旧版已注入的历史保留，不改写用户聊天。

对话内 MCP 工具从宿主传入的线程元数据取得当前 ID，查询 ClassCue 自己的
`drafts.sqlite`。快照读取限制在配置工作区内，并校验路径、图片类型、
大小、请求 ID 和文件 SHA-256；当前对话无绑定时停止。

`classcue/codex_native_draft.py` 在有时限的独立进程中执行附图。
先按绑定的线程 ID 深链导航，再检查官方 Codex 包身份、前台窗口、
对话当前标题及唯一可用的原生输入框。标题仅用于导航就绪核验，不用来查找或改绑对话。
导航阶段尚未粘贴时，允许发起点击的松开及鼠标移动；目标就绪、全部按键松开，
且键鼠输入连续静止至少 450 毫秒后，才建立输入保护基线。
持续操作超过导航时限则停止，不无限等待，也不发送粘贴按键。
附图前检查焦点和修饰键；检测到其他键鼠输入、焦点或窗口变化时停止。
UIA 可能随 Codex 版本或语言变化而失效；核验不通过时显示错误，不猜测坐标或向其他窗口粘贴。
正常路径临时恢复剪贴板；若进程异常退出或超过时限被终止，剪贴板可能仍保留此次原题。

通过 Windows UI Automation 聚焦唯一的当前输入框，移动光标到末尾，
以 `Ctrl+V` 追加文字和题图文件；不全选、不清空、不按发送键。
文字粘贴可能引起输入框重绘，图片阶段重新获取当前输入框。
图片走原生文件粘贴处理器。发出粘贴按键后记为 `pasted`，
只表示执行过粘贴，不代表已经视觉确认图片缩略图。
Codex 的 UIA 文字和附件信息可能仍来自旧对话，不用它们跳过首次粘贴或确认附图成功。
普通重开由持久回执防止重复；显式“重新附上原题”会追加一次，操作前需检查已有内容。
剪贴板原内容通过 OLE 实际复制到独立数据对象，完成后恢复；
不只保留会随剪贴板变化的对象引用。无法保存原内容时停止附图；
其间用户另行复制时保留用户的新内容。

传输状态：

| 状态 | 含义 |
| --- | --- |
| `pending` | 题目已登记，尚未执行桌面附图 |
| `inserting` | 已登记桌面附图操作，尚无最终回执 |
| `pasted` | 已向原生输入框发送粘贴按键，需用户检查缩略图后发送 |
| `attached` | 旧版本回执，仅保留兼容，不作为当前附件可见的依据 |
| `unknown` | 请求结果不明，停止自动重试 |
| `blocked` | 尚未粘贴，输入框或目标核验未通过，可以重新点击讨论 |

首次附图前持久保存 `native_transfer=inserting`；进程中断或回执未知不会自动重贴。
执行过粘贴的讨论后续只跳转。用户发送或移除附件后，历史回执不代表附件当前仍存在；
需要补回时在 ClassCue 点击“重新附上原题”，仍使用原讨论和原快照。
更新 ClassCue 自有回执库中的状态，阻止旧面板同时领取同一次传输。

ClassCue 界面显示原生附图结果，不再要求用户打开面板。
复制题图保留为讨论记录中的备用按钮，使用原版本题图；
复制成功只报告需要粘贴，不声称已附图。

## 视频片段讲解

视频复习页的播放器下方提供“讲解片段”。默认选取当前播放位置之前一分钟，
用户直接拖动原播放器进度条上的起止手柄选择范围，拖动时暂停并定位对应画面，
时间以只读读数显示；也可聚焦手柄后用方向键微调。副视角播放时仍使用主视频时间。
选好后点击“预览片段”打开弹窗并自动读取资料；“调整片段”返回播放器重新选取。
再选择要附上的精选 PPT，最后点击“在 Codex 中准备草稿”，
具体疑问直接在 Codex 输入框中补充。

草稿包含讲解请求、视频名称、选定范围、带原视频时间的教师字幕和图片对应时间；
PPT 走既有原生图片附件路径。用户可在 Codex 输入框中编辑文字、删除图片后自行发送。
不自动启动转写、PPT 提取或模型请求。所选范围没有字幕时不能准备；
没有精选 PPT 时允许仅用字幕。需要图片时先在原视频中完成 PPT 提取。

字幕采用与选定范围有交集的完整字幕句，不将句子按时间截断，也不重新估算词级时间。
边界句可能超出选定范围，草稿中保留原时间并说明这一点。
同时将完全相同的字幕保存为讨论目录内的 `subtitles.srt`，输入框内放入可编辑的 SRT
文字。当前不依赖 Codex 对字幕文件附件的解析，也不上传整段视频。

只选择 `is_llm_preferred` 的精选图，且其实际可见区间
`visible_from_ms/visible_until_ms` 必须与选定范围相交；不因同页组后面出现了
更完整的画面，就把该画面补到当前范围。图片按时间排序、按图片哈希去重，
同图保留本范围内的多个时间实例。取消勾选图片只影响本次草稿。
一次最多 23 张图片，学习上下文最多 20 MB；超出时缩小范围或减少图片，不静默截断。
发送前重新核对预览指纹、图片内容和路径，资料变化时要求重新预览。

片段沿用视频所在课程和视频资料目录；未归属课程的视频使用独立的“视频片段”分组，
不改变视频库归属。讨论身份包含视频内容、字幕、范围和图片选择；
同一输入重复准备沿用原讨论，历史记录可从片段弹窗重新打开。
预览指纹用于检查资料是否变化，讨论身份使用稳定的字幕、图片内容和时间实例，
不依赖 PPT 数据库行 ID；重新提取相同材料不会重复创建讨论。
预览、准备、打开及重新追加分别显示进度。图片读取失败会在对应图片下提示，
仍选中失败图片时禁止准备；用户可以取消该图或重新预览。
历史记录显示编号、图片数量和创建时间，打开历史不禁用当前片段的准备操作。
原生粘贴回执仍只表示执行过粘贴，不代表当前附件可见；
回执未知时检查 Codex 草稿，再明确追加同一片段。
已粘贴但后来被删除的草稿同样可明确重新追加；首次尝试后可选择“新建独立讨论”，
用于独立提问或原线程回执未知、被移除后的恢复，不自动重建旧讨论。
插件上下文使用原有格式版本，以 `source_kind=video_clip` 区分课堂片段，
面板和讨论技能支持字幕与 PPT，不要求用户打开面板才能附图。
