# 页面切换与轻量动效

本轮只调整现有界面的运动方式。页面、表单、播放器沿用原有实例和缓存，
导航与业务操作立即执行；不等待上一页或搜索窗口退场。

| 位置 | 运动 |
| --- | --- |
| 导入、批处理、设置页面 | 内容以 160ms 淡入；返回按钮、页标题和普通面板沿 X 轴从 6px 归位，浏览器返回方向相反 |
| 返回视频库 | 原有内容层 140ms 淡入；顶部、固定背景和已有卡片位置保持稳定 |
| 进入复习 | 标题与考点面板 140ms 淡入，播放器本体不移动、不因动画重新挂载 |
| 设置分类 | 标题与正文从下方 3px 淡入，正文晚 20ms，分别持续 140ms；首次读取在内容就绪时进入 |
| 文件夹窗口 | 打开 200ms、关闭 150ms；0.98 到 1 轻缩放，原点由所点文件夹位置计算，限制在窗口内部 |
| 任务详情 | 右侧 12px 滑入，打开 180ms、关闭 130ms |
| 全局搜索 | 窗口上移 4px 并淡入，打开 160ms、关闭 120ms |
| 搜索画面预览 | 保留 200ms 悬停意图检测；出现时上移 3px 并淡入 120ms，图片载入后 100ms 淡入 |
| 处理面板角色 | 在展开时晚 20ms 入场，上移 4px，持续 160ms；之后保持静止 |

## 实现约束

- `useEntryMotion` 使用现有 DOM 和浏览器原生动画。仅激活页面、改变设置分类、
  首次准备好该分类时启动；轮询、输入、进度变化不会重播。
- 隐藏或切换时取消当前动画，不排队、不复制 DOM，不改页面的 React key。
  开发环境 Strict Mode 的重复挂载检查不会吞掉入场。
- 只对普通内容部件施加位移。页面根层只做透明度动画，固定背景、浮层、
  视频画面不会因祖先 transform 改变定位。全宽返回栏只移动按钮，避免窄屏溢出。
- 设置按标题和正文分组处理，不对输入框、模型卡片逐条排队。
  新分类首次加载完成后播放正文入场，缓存刷新保持静态。
- 搜索结果选择立即导航；搜索窗口开始退出时释放焦点锁和背景交互锁。
  同视频跳转保留播放器实例。快速重新打开会中断退出，不触发延迟导航。
- 搜索预览位置即时更新，图片与标题使用同一业务 ID；保留旧的请求延迟、
  过期响应隔离和触屏规则。
- 系统启用减少动态效果时，不启动内容位移、淡入和角色动画；
  浮层使用零时长切换，图片透明度过渡沿用全局的减少动画规则。

效果对应参考：Modal Cards 的 fade / slide / scale，Depth Card 的分组 reveal，
Hover Preview 的悬停入场。均为项目内适配，不使用 React Bits Pro 源码。

## 验证

- `Motion.test.tsx`：切换中取消、草稿及焦点保持、减少动态效果切换、Strict Mode。
- `GlobalSearch.motion.test.tsx`：搜索立即导航与退场期间解锁、退出中再次打开。
- 现有工作台、设置、播放器、召回和搜索测试继续验证原有交互。
- `node tests/frontend_navigation_motion.cjs`：1440、1024、390px，双向导航、
  原页面和草稿实例、滚动恢复、快速切换、设置错峰、角色入场、抽屉重开、
  搜索预览和视频播放保持、减少动态效果。截图与录屏写入 `.runtime/`。
  脚本拦截写请求，只读本地媒体和字幕，不调用付费模型。
