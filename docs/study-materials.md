# 学习资料与手动选题

## 使用流程

首页“学习资料”进入 `/study-materials`，先显示与课程视频文件夹对应的课程资料夹。
新建资料夹时选择已有视频文件夹，或输入课程名称同时创建同名视频文件夹。
新建和更改关联的下拉列表默认只列第一级文件夹；已有子文件夹绑定保留当前选项，
不自动改动原绑定。课程仍默认包含其下各级视频子文件夹。
视频文件夹内的“本课程资料”直接进入已绑定课程；从子文件夹进入时优先沿父级查找已有课程。
课程按稳定 ID 绑定文件夹，改名同步显示；同名文件夹不会合并。
同一门课程包含子文件夹；显式为子文件夹另建课程时，该子树归最近的课程。
课程页的“更改关联”可纠正视频文件夹绑定，默认选中当前目录，
点击“保存关联”后生效；取消或保存失败保留原绑定。
其他课程已占用的文件夹不可选，变更不删除原文件夹，也不改变资料题身份。

进入课程的“上传资料”后，点击“导入资料”多选文件，或把文件拖入页面，
按所选顺序逐个导入；一份失败不会撤销其他成功文件。完成后打开第一份成功资料。
支持 PDF、Markdown、JPEG/PNG/WebP。新导入文件必须指定课程。
原有开发资料进入“待归属资料”，可勾选后移入课程；保留文件、题目和讨论身份。

课程的“视频例题”显示对应视频目录中已经保存题图的例题，复用原有截图和题目提取结果，
不重新截图、不调用模型。可阅读题图、跳回视频原时间，或用相同的单题入口进入 DSH。
视频题图替换保留题目 ID 并递增内容版本；题图缺失会明确提示回到视频修正。
视频例题归属随视频目录变化更新，已有讨论仍回到原会话。
删除视频文件夹保留课程资料夹、上传资料和讨论，允许重新绑定课程视频文件夹。

- PDF 和照片：切换到“选题”后可连续框选，每次有效拖框生成一道独立题目草稿，
  完成后仍保持选题模式。侧栏可切换草稿，保留各题的标题、题号、选区与撤销记录。
  点击已有题框可选择对应题目，再移动、拖动四角或用方向键微调；
  按住 Shift 增大键盘移动步长。侧栏也提供“调整选框”入口。
  “添加另一区域”使下一次框选追加到当前题，完成后恢复默认新增题目的行为。
  阅读模式隐藏全部题框，切回选题恢复显示与调整。
- PDF 连续跨页：从一页拖到下一页，靠近阅读区上下边缘会自动滚动，也支持反向拖选。
  页面间隙不作为题目内容保存；第一页保留起点以下区域，中间页保留整页，末页保留终点以上区域。
  一次拖拽产生的所有裁片属于同一道题的同一组，全部可调整；
  下一次独立框选默认生成另一题。Esc、指针取消或无效小框不改变已有题目；
  一次撤销移除本次跨页选区。
  调整已有选框的角点时，拖出原页上下边界可继续扩展到相邻页；
  同组在同一页上的重叠裁片合并，避免重复内容。取消恢复原框，一次撤销恢复本次调整前的整组。
  向上拖动时，鼠标略微移出阅读区侧边也继续按页顶位置自动滚动。
- PDF 默认启用“吸附文字边界”：按页提取全部有效文字的最左、最右位置，取最大宽度，
  不区分分栏、不排除页眉页脚，并向两侧各留 6 个 PDF 单位的余量。
  新框只向外扩展到这个范围，用户框得更宽时保留用户范围，高度始终由手动选择决定。
  边界用虚线标示；取消勾选或按住 Alt 可自由框选。图片和扫描 PDF 没有文字层时保留手动范围。
  文字边界不等于图表边界，超出文字范围的图表仍需用户框入，系统不会自动理解题目完整性。
- Markdown：切换到“选题”后，像 PDF 一样直接拖出矩形，覆盖到的内容块自动勾选。
  长题拖到阅读区边缘会自动滚动；每次拖框生成独立草稿，
  需要多次框选同一题时先点“添加另一区域”。一次撤销取消整次框选。
  Esc 可取消尚未完成的框选。左侧小复选框仅用于微调，也支持 Shift 连选。
  表格、代码和公式保留完整块，保存原始 Markdown 和行范围，不按框的屏幕像素裁断文字。
- 点击“保存题目”才写入当前题目；题号和标题可留空。多道题有未保存修改时可“全部保存”。
  已成功保存的题目不会因后续题目保存失败而在重试时重复创建。
  同一题显式追加的多个选区保存为一道完整题目；保存后仍可继续选题。
  点击已保存题目回到首个来源，裁片页码可单独定位；Markdown 的定位和移除放在“来源与选区”折叠区。
  Markdown 和连续跨页题目正文拼接显示，不显示逐块行号或卡片边框；来源操作收进折叠区。
  完整预览使用相同的连续排版，
  原始块 ID、行范围和题目身份保持不变。
- 原文始终只读。支持修改显示名称、编辑题目选区、补充本地题图，以及资料/题目移除恢复。
  内容范围变化递增题目版本，单纯修改标题和题号保持版本。

每份资料保存缩放、页码、滚动位置、当前题目和侧栏开关；重新打开恢复。
同课程切换上传资料与视频例题保留阅读器，离开时的阅读状态同时更新本地缓存，
避免保存请求尚未完成就重进时恢复旧位置。资料操作同步刷新课程列表数量。
桌面使用文件、原文、题目三栏，窄窗口通过“返回资料”“题目”“返回原文”逐层阅读。
课程阅读区占用剩余窗口高度，各栏独立滚动；资料页内切换不增加外层返回步骤，
外层返回保留进入资料前的工作台来源。
未保存的全部题目草稿沿用应用现有离开确认；切换题目本身不要求保存或丢弃其他草稿。

阅读工具栏的“专注阅读”可临时收起两侧栏，再次点击恢复原来的侧栏组合。
长文件名最多显示两行，悬停可查看完整名称。没有题目的新资料默认收起空题目栏。
题目列表位于侧栏顶部并独立滚动，长题预览不会把其他题目挤到页面末尾。
保存后的题目默认以只读摘要和原题显示，点击“编辑题目”才出现标题、题号和选区操作。
“完整预览”或点击裁片可打开支持缩放的整题阅读窗口，按 Esc 关闭。
编辑期间保存/取消固定在侧栏底部；窄窗口阅读时显示已选区域数和“预览并保存”入口。

## 数据与原文

原文件复制到当前库作用域的 `study-materials/<文档 ID>/original.<扩展名>`，
不移动、改写或删除导入前的文件。重复名称或内容各自登记，不筛重。
数据库只保存相对资源路径；应用数据迁移沿用既有 `library_identity.scope`，
数据库搬迁后继续读取原资料目录，资料资源本身不跟随小型配置迁移。

独立数据表：

| 表 | 用途 |
| --- | --- |
| `study_courses` | 稳定课程身份、课程名称、唯一视频文件夹绑定 |
| `course_questions` | 视频来源的稳定单题身份、题图指纹与内容版本；对外与资料题共用读取接口 |
| `study_documents` | 稳定文件身份、所属课程、显示名称、格式、哈希、阅读位置、移除状态 |
| `study_document_blocks` | PDF 页面尺寸、照片资源、Markdown 原文块与行范围 |
| `study_questions` | 稳定题目身份、所属资料、可选题号和标题、内容版本 |
| `study_question_regions` | 有序来源块引用、页面归一化矩形或完整文字块范围 |

PDF 导入只登记尺寸和页数，使用与渲染相同的 PDFium 页面方向。
页面接近阅读区时才请求渲染，磁盘缓存原页图，裁片从该图生成而非截取浏览器画面。
渲染最长边至多 2400 像素、倍率至多 3，保证阅读性能；不是 OCR 或可搜索 PDF 文字层。
照片读取 EXIF 方向后生成只读页面，坐标始终指向方向修正后的资源。
选题时按需使用 PDFium 字符边界提取页面文字最大包围框，沿用 PDFium 坐标转换，
适配页面旋转及裁边；结果缓存在来源块的 `text_bounds` 字段，不修改原 PDF，也不需要重新导入。
无文字层、无法提取或单页字符数超过处理上限时，保留原文阅读和自由框选。
跨页裁片的 `selection_group` 保存在原有区域 JSON 中，无需新增数据库表。

Markdown 使用 UTF-8，保存原始文字和行范围，安全渲染标题、段落、列表、表格、代码和公式。
不执行原文 HTML，不请求外部图片或任意本机路径。缺图显示占位，
可以通过“补充题图”添加受管理的本地图片，与原文字一起组成一道题。
首版不提供 DOCX、自动 OCR、全文检索、分类、学习状态或自动模型调用。
桌面端已保存题目可通过[单题 DSH 桌面桥接](dsh-desktop-bridge.md)
放入 DSH 原生草稿并返回原讨论；编辑中的题目不会显示讨论入口。
旧 `/materials` 继续由原功能开关控制，默认关闭。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET/POST /api/study-courses` | 课程资料夹列表、新建课程并绑定或创建视频文件夹 |
| `GET /api/study-courses/folders` | 可选视频文件夹及绑定关系 |
| `GET /api/study-courses/for-folder/{id}` | 获取最近的所属课程，包含父级查找 |
| `PUT /api/study-courses/{id}/folder` | 绑定课程的视频文件夹 |
| `GET /api/study-courses/{id}/video-questions` | 本课程带题图的视频例题 |
| `GET /api/course-questions/video/{marker}` | 将原视频例题转换为统一单题引用 |
| `GET /api/course-questions/{id}` | 读取资料题或视频例题的课程、来源、内容版本 |
| `GET/POST /api/study-documents` | 列表、逐文件导入；导入必须传 `name`、`course_id`，请求体为原始文件字节 |
| `PUT /api/study-documents/{id}/course` | 手动调整资料所属课程，保持题目身份与讨论历史 |
| `GET/PUT/DELETE /api/study-documents/{id}` | 读取资料、修改显示名称、可恢复移除 |
| `POST /api/study-documents/{id}/restore` | 恢复资料及其未单独移除的题目 |
| `GET /api/study-documents/{id}/blocks` | 按原文顺序读取结构块 |
| `GET /api/study-documents/{id}/page/{page}` | 按需渲染/读取页面 PNG，页码从 1 开始 |
| `GET /api/study-documents/{id}/blocks/{block}/region` | 按 `left/top/right/bottom` 归一化坐标预览 PNG |
| `GET /api/study-documents/{id}/blocks/{block}/text-bounds` | 按需提取并缓存页面全部文字边界；返回归一化 `bbox` 及 `ready/no_text/unavailable` |
| `PUT /api/study-documents/{id}/reading` | 保存阅读位置、缩放及当前题目 |
| `POST /api/study-documents/{id}/attachments` | 添加受管理的本地补图 |
| `GET/POST /api/study-questions` | 按 `document_id` 查询题目，或保存新题目 |
| `GET/PUT/DELETE /api/study-questions/{id}` | 读取、修改、可恢复移除题目 |
| `POST /api/study-questions/{id}/restore` | 恢复题目 |

列表默认不含移除记录，`include_deleted=true` 可读取回收内容。
`course_id` 筛选课程资料；`unassigned=true` 仅返回待归属文件。
来源块必须属于当前资料，图像矩形必须位于页面内，Markdown 首版只接受完整内容块。
文档移除使所属题目不可用于普通阅读；恢复文档不复活用户单独移除的题目。

## 开发验收

后端合成资料覆盖多页/扫描/旋转 PDF、照片方向、Markdown 结构、重复导入、
内容版本、越界来源、原文回访、移除恢复、补图与数据库迁移作用域。
前端测试覆盖手动选择、连续选择、撤销、取消、保存失败与安全阅读。

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_study_courses.py tests/test_study_materials.py tests/test_application_data_migration.py tests/test_release_manifest.py -q
Push-Location frontend
npm test -- --maxWorkers=2 --minWorkers=1
npm run build
Pop-Location
```

浏览器脚本只接受带合成库标记的隔离服务，不能指向真实应用。
使用项目已有 Playwright 安装；如在其他位置安装，设置 `CLASSROOM_PLAYWRIGHT_MODULE`。
先在一个终端启动测试服务，再在另一个终端运行脚本，结束后停止该测试服务：

```powershell
.\.venv\Scripts\python.exe -c "import runpy; runpy.run_path('tests/study_material_browser_server.py', run_name='__main__')" --root .runtime/study-qa --port 18880
node tests/study_materials_browser.cjs
```

默认浏览器为本机 Edge；`CLASSROOM_BROWSER_CHANNEL` 可覆盖。
`CLASSROOM_STUDY_QA_URL`、`CLASSROOM_STUDY_FIXTURES` 可分别指定隔离服务地址与合成文件目录。
截图及结果只写入已忽略的 `.runtime/study-materials-browser/`，不加入发行包。
验收包含部分导入失败、连续拖拽跨页及自动滚动、文字最大宽度、组内编辑及重开、键盘微调、
缩放重开、Markdown、未保存提示、
改名、删除恢复和 1440/1280/768/390 像素窗口，检查无模型及外部图片请求。
