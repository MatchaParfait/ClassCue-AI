# 全局字幕搜索

已接入现有 `GET /api/library/search`，搜索范围为视频库所有文件夹中已保存的字幕。入口位于视频库、处理页、设置页及复习页顶部，支持 Ctrl+K / Cmd+K；小屏显示搜索图标。

- 按视频分组展示标题、所在文件夹、全视频命中数和字幕时间。黄色标出命中词，浅绿色标出键盘选中项。
- 支持中文短词和原文匹配；不搜索文件名、文件夹名或 AI 考点，不增加语义搜索。
- 输入防抖 250ms，输入法组词期间不发请求。空输入清空结果；超过 120 个字符时显示提示。
- 请求支持取消及过期结果丢弃。每次加载 20 条，跨页合并同视频分组并以视频和字幕 ID 去重；刷新结果从第一页重新加载。
- 方向键选择、Enter 跳转、Escape 关闭，Tab 限制在弹窗内。关闭恢复焦点；支持在文件夹窗口、任务抽屉和复习设置上方打开搜索。
- 搜索保留当前页面、草稿和播放状态。会话内保留关键词及已加载结果；库标识变化时清空，校验接口返回的 `library_id`，不写入持久化配置。
- 点击结果打开 `/review/:videoId?start_ms=…&library_id=…`。等待视频元数据后跳转，优先于播放进度恢复；同视频重复选择也重新定位。搜索不调用考点修改接口、不标记已看、不覆盖手动跳转时间。
- 外观使用现有主题变量、浮层动效和减少动态效果偏好。保留原方框主题文件。

## 候选画面预览

鼠标停在候选字幕上200ms后，读取该字幕开始时间对应的静态画面。
键盘上下键选择也会预览，焦点继续留在搜索框，Enter仍执行跳转。
预览独立于主播放器，不播放音频、不修改播放位置或已看状态。
触屏移动不触发悬停预览，点选字幕保持原有跳转行为。

预览浮层不占用列表空间，最大宽度560px。宽屏优先放在弹窗外侧；
空间不足时缩放后放在当前候选项上方或下方，保持候选项可见且不超出窗口。
窗口过矮无法容纳时隐藏预览。图片保持原始比例，附上视频名、时间和字幕原文。
移开鼠标、滚动列表、修改关键词或关闭搜索会清除悬停预览；
切换候选项时隐藏旧图，避免迟到图片覆盖当前候选项。
截图读取失败只显示占位提示，点击字幕和键盘跳转仍然可用。

新增只读接口：

```http
GET /api/videos/{video_id}/preview-frame?time_ms=1877520&library_id=...
```

校验视频库与非负时间，将超出视频时长的时间限制在结尾。
从前一个视频关键帧开始解码，截取请求位置画面；JPEG保持完整构图，
最长边上限960px，不放大小视频。依据源文件身份、时间和截图版本缓存到
当前音频缓存目录的 `search-previews` 子目录；文件变化后重新生成。
共享现有的两路解码限流和文件锁，缓存命中直接读取，不修改源视频。
视频库不匹配返回409，视频或画面不可读返回404，不创建处理任务。

## 实现位置

- `frontend/src/components/GlobalSearch.tsx`：共享会话、输入请求、分组、键盘与焦点。
- `frontend/src/search.css`：胶囊入口、结果浮层和响应式布局。
- `frontend/src/searchNavigation.ts`：校验时间和视频库参数。
- `frontend/src/components/VideoPanel.tsx`：元数据加载后消费导航时间。
- `frontend/src/api/client.ts` / `types.ts`：接口及响应类型。
- `frontend/src/components/SearchFramePreview.tsx` / `searchPreviewPlacement.ts`：悬停延迟、图片状态和避让定位。
- `video_thumbnail.py` / `api/main.py`：按时间取帧及本地缓存接口。

## 验证

```powershell
cd frontend
npm run build
npm test
```

临时真实后端与媒体的浏览器验证（从仓库根目录运行，前端须已启动）：

```powershell
$env:SEARCH_QA='1'
node tests/frontend_workbench.cjs
```

运行会建立独立数据库与测试视频，接口请求转发到临时后端，不写真实视频库。截图、动效录像及 `search-qa.json` 保存至 `.runtime/workbench-qa-<timestamp>/`。

浏览器覆盖真实搜索及分页、键盘和焦点、播放进度优先级、同视频重复定位、跨页面保留搜索、文件夹内叠加浮层、设置草稿、减少动态效果及 1440 / 1024 / 390px 布局。单元测试补充输入法、过期响应、分页去重、连接的视频库标识变化、失败重试与 URL 边界。

预览专项测试：`tests/test_search_preview.py` 校验帧内容、并发缓存、
分辨率、源文件变化、视频库隔离与失败降级；前端搜索和定位测试校验延迟、
快速切换、键盘、触屏和浮层边界。
`node tests/frontend_search_preview.cjs` 在独立浏览器上下文中只读检查本地视频，
默认使用“汉诺塔”关键词，可通过 `SEARCH_PREVIEW_QUERY` 指定至少三个命中的查询。
生成的截图及报告位于 `.runtime/search-preview-qa-*`，不会调用AI或修改复习数据。
