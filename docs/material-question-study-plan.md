# 资料题目与 DSH 学习记录开发计划

## 状态与方向

**状态：本地导入、阅读、手动选题、课程归属及单题 DSH 桥接已实现；
默认根目录下的课程／资料工作区树已实现，题目学习记录尚未实现。**

首页“学习资料”进入 `/study-materials` 课程资料夹页面。本地阅读与选题可独立使用，
桥接只准备 DSH 草稿，不自动调用模型。旧“复习资料”分类模块继续关闭。
当前实现和验收命令见[学习资料与手动选题](study-materials.md)及
[单题 DSH 桌面桥接](dsh-desktop-bridge.md)。

2026-10-30 已实现新的组织方式：用户在 App“设置 → DSH 讨论”中选择一次默认根目录，
后续自动维护“默认根目录 → 课程目录 → 资料文件目录 → 单题会话”。
题目旁的连接设置共享同一根目录；新讨论无需再去 DSH 选择地址。
新目录策略以[DSH 工作区树方案](dsh-workspace-tree-plan.md)为准。
本文以下历史分阶段描述尚未逐项同步；涉及会话接入的实际完成范围以桥接文档为准。

后续方向不再是“建立分类题库并由 Agent 整理、关联考点”，而是让学生从自己的资料中
亲手选定一道完整题目，将它绑定到 DSH 的持久对话；讨论结束后，用户主动生成该题的学习记录，
以后从原资料可以回到原来的讨论。

用户主流程：

1. 从课堂回放复习老师讲过的考点。
2. 需要练习时，在自己的 PDF、图片或 Markdown 资料中打开原文。
3. 用直观的选择或裁切操作框选**一道完整题目**，确认预览后保存；未来再支持发送给 DSH。
4. 在 DSH 中继续讨论；结束本轮时，按一下生成题目学习记录。
5. 下次从同一资料、同一道题打开，继续原 DSH 对话或查看已有学习记录。

资料阅读、题目边界和会话绑定由用户掌控。首版不自动拆题、不分类题库、不匹配视频考点、
不替用户找题，也不运行资料整理 Agent。分类标签最多是以后可选的人工整理能力，不是本功能前置条件。

## 与现有资料库的边界

现有资料库功能仍通过 `VITE_ENABLE_MATERIALS` 保持默认关闭；本计划不开启它，
也不以现有 `MaterialsPage`、分类流程或自动整理任务作为新功能的产品基础。
现有资料库按分类浏览、自动 Agent 逐小问提交、学习状态与答案关联组织，
这些流程不符合“用户从原资料裁出整题并绑定 DSH 会话”的主路径。

现有代码仅在后续评估后复用通用底层能力，例如 PDF 页面解析/渲染、Markdown 安全渲染、
资料资源的本地复制与路径隔离。复用时要独立评估接口和数据兼容性，不能因为代码已存在
就继承不合适的目录、题目约束或分类语义。本轮使用独立解析入口、页面、接口和数据表，
不迁移旧资料，不启用旧分类目录及自动整理流程。

## 目标与首版范围

### 必须完成

- 资料导入和只读阅读：支持 PDF、Markdown、JPEG/PNG/WebP；原文件留在原位置，应用使用自身管理副本。
- 用户手动框选完整题目，可以由一个或多个页面/区域组成；不将题目里的（1）（2）小问拆成独立题目。
- 保存题目和原文定位，关闭后重开仍能找到并显示正确范围。
- 文件与题目支持可恢复移除；独立保存每份资料的阅读位置、缩放和当前题目。

### 后续集成范围

- 一道题可以创建 DSH 对话，后续从原题继续进入该持久会话。
- 用户主动结束一轮并生成版本化的题目学习记录；旧记录与原对话保留。
- DSH 不可用、会话被移除或总结失败时，本地题目与已保存记录仍可读。

### 首版不做

- 自动题目识别、Agent 拆分、向量检索、知识点/题型分类和视频考点匹配。
- 自动判断用户“学会”或静默生成总结。
- 新建聊天模型运行时或仿造 DSH Harness；模型与对话由 DSH 管理。
- 任意文档脚本、外链图片、宏或嵌入内容的执行。
- 把 DSH 内部数据库格式当成稳定公共接口直接读写。

## 用户界面与选题交互

### 资料工作区

资料是轻量的原文工作区，而不是自动生成的课程目录。布局以文件列表、原文阅读区和当前题目为主：

- 用户导入或打开 PDF、图片、Markdown；保留文件名、页码/行号和原文顺序。
- 最近打开的资料与题目提供恢复入口；不强迫用户先建立课程、主题和题型树。
- 当前题目可改标题或题号，但原文出处和来源区域是主要身份依据。
- 首次打开原资料时显示文件内页码/行号定位和缩放，文件列表支持名称搜索；不自动把整份文档转成题库条目。

### PDF：视觉框选

1. 用户点击“选取一道题”，指针和页面状态明确进入框选模式；普通滚动、缩放和链接操作不误触发选区。
2. 在页面上拖出矩形，页面旁显示可调整边框、页码和裁切预览。
3. 题干跨页或依赖前置条件时，点击“添加范围”，继续在其他页补选。所有范围组合成**同一道题**。
4. 用户可移除或重排范围，重新裁切，并选择是否附带相邻的公共题干/图表。
5. 右侧预览展示全部题图；点击“保存题目”才写入数据库。DSH 发送留待后续。

裁切区域应使用原 PDF 页面坐标而不是当前屏幕像素，保证缩放、窗口大小和重开阅读器后仍能准确定位。
最终裁片从足够清晰的页面图像生成；原始页面与选区元数据一并保留，避免只存低清屏幕截图。

### Markdown：文字选择与图像范围

- 按原文结构块点选，支持 Shift 连选，映射回 Markdown 原文件行范围，
  不依赖渲染后的 DOM 偏移。单个列表项可独立选取，其内部小问保持在同一个块中。
- 对表格、公式和代码块提供清楚的选择边界，发送预览尽量保留原始 Markdown 语义。
- 可添加多个非连续文字范围，组合成一道跨段/跨节题；保留其原始顺序。
- 内嵌或引用图片如不能安全、稳定地解析，显示具体问题并允许用户补充本地题图，
  不自动访问外部 URL 或用户机器任意路径。

### 选题确认与发送

当前界面显示题目预览、资料名、页码/行号、可选题号/标题和编辑、保存操作。
未来发送前再确认目标；不能因画完选区就自动调用模型或自动发送。

鼠标拖选必须有键盘可操作的替代方式，例如“添加页面范围”后通过页码和边界数值调整；
提供撤销最近选区、清空、取消和删除单一区域等可发现的动作。触屏下有可拖动手柄和放大预览。
小范围、越界或空范围要就地提示，不静默保存错误裁片。

## DSH 会话与插件集成

ClassCue 管资料题目和外部会话绑定；DSH 管模型调用、对话消息及 Harness 上下文。
通过 DSH 正式支持的插件/客户端扩展能力建立一条受控连接，不共享密钥、不复制另一套会话运行时。

实现前先完成接入探针，确认所选 DSH 版本的能力：

- 插件能否从 ClassCue 请求“新建对话并注入题目文字/图片”。
- 插件能否返回可持久化且唯一的会话 ID。
- ClassCue 能否按该 ID 恢复同一会话，并定位到会话内较早讨论。
- 能否显式请求当前会话摘要，并取得消息范围、摘要结果和错误状态。
- DSH 关闭、升级、工作目录变化、会话删除或接口不兼容时的行为。
- 图片能否经过正式输入协议到达会话；若不支持，明确采用可读 OCR 文本或暂不支持该题型。

不得假定“插件存在”就代表外部应用可以任意创建、唤起或恢复 DSH 会话。若没有稳定的公开入口，
先确定并实现一个受支持的 DSH 插件命令/本地桥接；不要依赖私有数据库表、手拼内部 URL、
窗口标题搜索或模拟键盘点击作为会话身份机制。

### 一题多轮讨论

- 默认每个题目有一个主会话：首次发送创建；之后“继续讨论”恢复原会话。
- 用户可以显式“开始新的讨论”，新会话与旧会话并列保留，不能覆盖旧记录。
- 会话绑定至少包含题目 ID、题目版本、DSH 实例/工作区身份、会话 ID、创建时间和状态。
- 发送使用幂等请求 ID。发生超时但结果未知时先查询/恢复请求状态，避免重复创建会话或发送两遍题目。
- 会话恢复失败时保留绑定记录并提示重试、重新绑定或查看本地学习记录；不得悄悄新建一个会话冒充旧会话。
- 原题被修改时，旧会话仍对应原题版本；新版本可继续查看旧讨论，但开始新讨论时明确绑定新版本。

## 题目学习记录

“生成本轮学习记录”由用户主动点击。按钮针对当前 DSH 会话尚未总结的消息范围工作；
总结失败可重试，成功后生成一个新版本，不覆盖此前记录或原始对话。

首版记录结构建议：

| 字段 | 含义 |
| --- | --- |
| 题号与标题 | 用户确认的题目名称/题号，可为空 |
| 题目出处 | 资料名、原页码/行号和题目原文链接 |
| 题目快照 | 当时发送到会话的文字/图像来源及题目版本 |
| 关键解法 | 对话确认过的主要方法、步骤、条件或结论 |
| 用户思考 | 用户实际提出的思路、尝试和问题；不得由模型臆造 |
| 易错点/待澄清 | 仅从用户明确表达的错误或对话尚未解决处提炼；没有证据就留空 |
| 后续提醒 | 下次复习时值得重新检查的问题，可为空 |
| 会话定位 | DSH 实例、会话 ID，以及支持时的消息 ID/总结覆盖范围 |
| 记录元数据 | 创建时间、使用的题目版本、总结版本、状态及错误信息 |

记录正文以学生能复习的表达呈现，不假定用户一定犯过错。模型总结中关于“用户误区”的陈述必须能追溯
到用户发言；模型自己提出后又修正的错误不能记到用户名下。输出需结构校验，缺字段、空讨论或不完整响应
不能替换旧记录。

总结输出目标是本地可读的结构化数据，可提供 Markdown 展示/导出；DSH 自己的上下文压缩属于另一机制，
不能把 Harness 压缩摘要直接当作学习记录。

## 数据与边界

建议独立设计轻量持久化表，不复用现有 `material_items` 的分类必填和内容约束：

- `study_documents`：资料文件的本地资源引用、格式、哈希、显示名及移除状态。
- `study_questions`：稳定题目 ID、题目版本、可选标题/题号、用户确认时间。
- `study_question_regions`：按顺序记录原文定位。PDF 使用页码及归一化矩形；Markdown 使用原文范围；
  一个题目允许跨页、多块。
- `study_conversations`：题目及内容版本到 DSH 实例和会话 ID 的绑定，可有多个历史会话。
- `study_records`：会话范围、总结版本、结构化内容、状态和可重试错误类别。

本地首版已建立前三类数据及 `study_document_blocks`，不预建会话或学习记录表。
后两类表待接入探针后定稿；检查 SQLite 数据迁移、应用数据目录迁移、数据库备份与发行清单。
原文件不因题目拆分而复制多份，题图裁片作为派生缓存可按需重建；人工补图作为独立资源保存。
记录中不保存 API 密钥、访问令牌、DSH 鉴权内容或不必要的完整聊天副本。

## 分阶段实施与退出条件

### 已实现：独立本地导入、阅读与手动选题

- 首页“学习资料”直接多选导入或拖入文件，不需要创建资料集。
- PDF 页面按需渲染；PDF/照片可框选、移动、调整、跨页组合、预览、撤销并保存为完整题目。
- Markdown 按结构块选择，保存原始文字及来源行范围；保留公式、表格、代码和列表。
- 支持标题/题号、选区内容版本、原文定位、阅读恢复、补图、移除和恢复。
- 使用临时数据库与合成资料验收；旧分类资料库保持关闭，不调用 AI/DSH。

**退出条件：** 本地保存和回访可以独立使用，不依赖未来 DSH 接入结果。

### 后续阶段 0：DSH 可行性探针

- 固定以“完整题目”为一个学习单元，小问作为题内结构，不创建独立会话。
- 在隔离、合成内容下验证 DSH 插件新建、传入文字和图片、返回会话 ID、退出重开后恢复。
- 验证当前会话生成可校验的摘要，并能识别消息覆盖边界。
- 记录 DSH 版本、正式扩展点、图片能力、失败模式和本地/远端隐私边界。

**退出条件：** 可以由 App/插件创建并确定性地恢复指定会话。若失败，暂停会话集成，
保留已交付的本地阅读与选题，先解决受支持的桥接方式；不以私有数据库读写或自动化点击绕过。

### 阶段 1：手动资料阅读与选区（已实现）

- 完成本地 PDF、图片与 Markdown 阅读，不启用旧资料库入口。
- 实现 PDF 单页/跨页多区域框选、裁片预览和重开坐标恢复。
- 实现 Markdown 结构块点选、行范围映射和多区域组合。
- 通过用户试用确认“整题连同题干、图表和所有小问”的选择过程是否自然。

**退出条件：** 用户无需 Agent 即可稳定保存、重新打开并准确预览一整道题；放大、缩小、
切页及窗口尺寸变化不会使定位漂移。

### 阶段 2：题目、来源与本地恢复（已实现）

- 建立新的轻量资料、题目和来源区域存储模型。
- 完成导入、列表、原文阅读、手动新增/改名、选区增删、恢复和软删除。
- 暂不接会话；先确认本地数据迁移、备份、资源校验和隔离测试策略。

**退出条件：** 应用重启和数据库迁移后，原题、裁片/文字范围与原文入口仍准确。

### 阶段 3：逐题 DSH 会话绑定

- 加入 DSH 插件桥接，逐题创建/继续/另开会话，绑定当前题目版本。
- 处理请求幂等、DSH 未启动、发送超时、未知回执、外部删除和重绑定。
- 展示会话状态及最近访问；从原题一键返回持久对话。

**退出条件：** 两道题互不串会话，关闭两端后各自准确恢复；重复点击不会重复创建或发送。

### 阶段 4：生成题目学习记录

- 接入当前会话摘要动作，按消息范围版本化保存记录。
- 实现结构化字段校验、错误重试、重复请求保护、记录浏览与原题/原会话回链。
- 用有明确用户错误、没有错误、讨论未完成、模型自纠正等合成对话验证“误区”归因。

**退出条件：** 多轮摘要不覆盖旧记录；用户思考/误区有可核对的对话依据；失败时原会话和历史记录完整。

### 阶段 5：真实资料形态与可用性验收

- 扩展 PDF 扫描页、照片题、公式/表格 Markdown 和跨页题。
- 在不同屏幕与触屏下验证裁切、预览、键盘替代操作和返回原题定位。
- 检查外部 DSH 升级、缺席、会话删除、库迁移、文件重命名及题目版本变化。
- 再决定是否支持 DOCX、图片 OCR、手动分类或更丰富的复习统计；均不作为首版前置。

**退出条件：** 合成端到端测试通过，并由用户抽样确认选区与会话链接可用。
本地阅读入口独立开放，不以会话集成作为前置条件。

## 测试与安全验收

- 后端使用临时 SQLite、合成 PDF/Markdown 和假 DSH 桥接，不访问用户真实资料或真实模型。
- 前端测试覆盖新建题目、选区跨页组合、取消/撤销、重启恢复、会话状态和摘要版本。
- 浏览器验收检查 PDF 选区坐标、裁片清晰度、Markdown 精确定位、桌面/窄屏/触屏无溢出。
- DSH 集成测试使用隔离工作区；默认不开启网络和付费模型，除非未来单独明确授权实测。
- 只向用户选择的 DSH 会话发送已确认题目及必要上下文；先说明资料发送范围和 DSH 使用的模型/服务边界。
- 不加载文档主动内容，不外传整份资料；会话标题或摘要不能包含凭据和本机绝对路径。
- 对外部返回值按不可信数据处理；会话链接使用允许的协议和本地地址校验。

## 当前决策摘要

- 旧分类资料库继续关闭；独立“学习资料”提供本地导入与手动选题。
- 用户手动裁切/选择一道完整题目；Agent 自动拆题不在范围内。
