# 通过 USB 与平板交换课程

Windows 和 Android 应用可通过数据线双向传送视频、字幕、考点和课程文件夹。
传输使用 Windows 自带的文件传输能力，不需要 Wi-Fi、电脑端共享目录或用户安装 ADB。
接收端会保存自己的视频副本，不移动或删除发送端的原视频。

离线修改考点和考题后，使用[学习修改同步](features/study-sync.md)合并两端修改。
已关联视频禁止旧整包覆盖，避免丢失独立编辑与移除记录。

## 首次连接

1. 在平板打开“连接电脑”，按系统提示授权一个专用接收目录。
2. 用支持数据传输的 USB 线连接电脑，解锁平板，将 USB 用途选为“文件传输”。
3. 在电脑视频库点击“连接平板”，选择设备并点击“配对”。
4. 核对两端显示的六位配对码，在两端确认。之后同一设备可复用配对。

传输期间让平板保持在连接页面。切到后台时接收会暂停，回到前台后继续。
只有充电功能的数据线不能用于此功能。不同厂商的 USB 菜单名称可能不同；
具体兼容性还取决于系统提供的文件传输和目录授权能力。

## 电脑发送到平板

在文件夹右侧点击数据线图标，或打开视频的更多菜单选择“发送到平板”。
也可以在“连接平板”中选择课程文件夹或单个视频，然后点击“发送到平板”。
发送文件夹会包含子文件夹及其中的视频。

平板会显示接收预览。相同视频复用本地副本；相同资料不重复导入。
学习资料存在差异时默认跳过，用户可明确选择覆盖并保留覆盖前备份。
确认接收后开始传输，接收端完成校验和入库才会显示完成。

## 平板发送到电脑

在平板连接页面选择课程并发送，在电脑“连接平板”的传输记录中检查接收预览，
选择目标文件夹和各视频的接收操作，点击“确认接收”。
接收的媒体保存在电脑当前视频库配置的目录。

传输记录提供暂停、继续和取消。中断或重新打开应用后，已确认的数据块可继续使用。
部分条目失败时，成功条目保留；电脑发送记录中的“重新发送失败项”会发起新的接收确认。
取消只清理未入库的临时内容，不删除此前已经入库的视频。

## 覆盖与恢复

覆盖会整体替换相应视频的字幕和考点，不合并两个版本。发送者的考点重要程度、
定位修正和已完成方案随资料一起传送，包含没有考点的方案。
“本次已看”和播放进度不作为学习资料交换。

电脑接收覆盖时会保存原资料备份，七天内可在连接窗口的“覆盖前的备份”恢复。
确认接收后如果资料被其他操作修改，入库会拒绝覆盖并显示该条失败，
不把后来的本地修改悄悄替换掉。

## 实现与边界

- Windows Portable Devices 的 COM 操作在独立工作进程运行，不在 API 线程中加载 COM。
- 专用目录内使用签名控制消息，P-256 设备身份由 Windows DPAPI 保护。
- 视频按 32 MiB 分块；学习包及视频块关闭写入后，另写签名提交标记。
  接收端验证签名、大小、块哈希和完整视频 SHA-256 后才入库。
- 数据块写入本地暂存文件、刷新到磁盘并记录日志后才确认。
  中断恢复按已确认块继续，损坏块可以重新传送。
- 传输日志与处理任务分离，入库事务保存提交记录，避免崩溃后重复导入。
- 两个应用独立实现协议，不共享运行时、源码模块或数据库。
- 学习资料继续使用 `.studyshare v1` 严格校验。视频大小上限为 1 GiB，
  时长上限为一小时，学习包上限为 32 MiB。完整视频哈希和大小必须一致，
  媒体时长探测仅允许 100 毫秒差异，不修改字幕时间。
- 文件传输不等于完整设备备份，也不传送模型、API 配置、密钥、截图或处理缓存。
