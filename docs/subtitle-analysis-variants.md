## 以下为保留粒子版的设计记录

轻量版保留原有的分层文字、附加微粒、扫描光带与考点反馈。

旧版本设置曾提供以下选择（粒子入口现已隐藏）：

- **轻量版**：原字形渲染路径，不创建字形粒子缓存或粒子几何。
- **粒子版 · 高性能设备**：只在 LLM 分析布局完成后，将字形替换成真实笔画像素采样的颗粒。主体笔画稳定，少量边缘颗粒沿局部笔画方向轻微流动；每次只有一句文字接受窄金光梳理，真实考点凝聚并沿阅读顺序变绿，不显示独立绿色圆环。

版本独立保存在 `classroom.experimental.subtitle-space.quality.v1`（`low` / `high`）。开关、演示与实际任务数据保持独立，选择版本不会启动或修改任务。未设置或无效值按轻量版处理。

粒子路径位于 `experiments/subtitle-cyberspace/src/particle-text.js`。每个字形只采样一次；最多 1,800 个装饰字符，正面、立体侧缘、拖尾实例合计不超过 280,000 个，通过实例化几何批量绘制。每帧更新时钟和字符状态纹理，字形位置缓存只在内容或布局改变时重建。

减少动态效果、等待、暂停时立即停止循环并关闭拖尾；完成时收完新命中的确认动画后停止，保留静态立体字形。隐藏窗口时暂停整个渲染循环。持续低帧率时先释放拖尾和侧缘、保留正面颗粒；仍持续缓慢时退回轻量绘制并提示。采样失败直接回退，不修改用户保存的版本。退出时释放所有几何、材质和共享状态纹理。

ASR 阶段沿用原有无穷符号；粒子版资源在第二阶段才创建。原字体与粒子只在 200ms 交接阶段交叉淡化，之后字形完全由粒子构成。

## 粒子版运动编排

- 从字形周围 7×7 像素的墨迹分布估算笔画切线与边缘程度，和字形一起缓存。不是识别真实书写笔顺；染色在字符内部按左上至右下推进，字符之间按原文顺序推进。
- 待分析时主体不动，约四分之一的边缘采样点轻微游动。每 3.6 秒选择一句尚未全部命中的文字，窄金光前方短距离松动、沿笔画流动，后方恢复紧密。背景轮廓与旧金色扫光保留但减弱。
- 分块接口只有序号和数量，没有当前块的精确字幕范围。因此局部梳理仅表示分析活跃，不声称某个字正在由模型读取，不影响真实进度。
- 真实命中约 800ms 完成收拢、染绿和稳定；批量命中最多增加 240ms 错峰。已经命中的字停止游动，不因轮询或正式结果替换预览 ID 而重播。
- 鼠标靠近时局部文字稍亮、颗粒运动收紧，不吸附、不移动字的位置，不改变考点点击区域。触屏和减少动态效果关闭这一反馈。
- 高性能版分析背景使用约 26 秒周期的暖金、奶油色光场，与局部梳理和命中的短节奏分离；命中不会让背景闪绿。轻量版及 ASR 背景保持原样。
- 不增加 28 万的总预算。正面字形保持原采样优先级；侧缘和拖尾只使用剩余预算，分别最多 24,000 / 10,000 个实例。切线、阅读顺序及侧缘法线缓存为静态属性，三组绘制共享状态纹理、时钟和运动函数，空闲时跳过拖尾绘制。

## 立体字形与细丝拖尾

- `particle-shaders.js` 为正面、侧缘和拖尾提供同一运动函数。正面保留清晰的笔画采样，颗粒增加柔和球面光照；侧缘沿所属文字平面的真实法线向后延伸两层，最深为字宽的 13%。侧缘金色、背面较暗，随相机和鼠标光照产生细微变化，点击仍使用原来的正面坐标。
- `particle-accents.js` 只从前景笔画边缘挑选附加样本，均匀分散预算。拖尾使用三段细带采样过去最多 240ms 的世界空间轨迹，按当前相机投影，不累积屏幕残影。长度上限为字宽的 30%，尾端收细且透明，主要在金光经过时显示。
- 真实命中开始时，拖尾沿收束轨迹回到笔画，历史窗口随染色推进缩短，最终完全关闭；侧缘短暂亮起后稳定为绿色。正式结果替换预览 ID、轮询及视角移动不会重新触发命中拖尾。
- 慢帧累积超过 3 秒时先释放附加几何；继续缓慢超过 5 秒才沿用完整回退。不会通过减少正面采样来换取更多装饰粒子，也不会因下一次轮询重新启用被降级的附加层。


### 大角度转向时字幕带甩出修复（2026-10-19）

- 根因在原始 `referenceRibbon.update()` 的离屏尾部构造：依据相机空间的前后关系与投影方向重新生成 Bézier 终点。大角度转向经过分支边界时，可见尾部发生大幅几何位移；与字幕外移使用的 UV 相位无关。
- 生产场景新增 `gravity-ribbon-tail.js`，按主体端点和切线一次性生成固定于场景的延伸曲线，原主体顶点、UV 和字符身份保持不变。尾部字距继续使用真实弧长，最后 55% 平滑渐隐；不再每帧把尾部追随到相机外。参考源码和参考纹理对照路径保留。
- 同一组 8 次连续考点转向的浏览器对照中，旧尾部出现 84 次可见顶点单帧位移超过 3 场景单位的记录，最大约 13.41；固定尾部版本为 0 次。54 项相关测试及前端构建通过，新增主体不变、接缝字距连续、大角度转向不改变尾部几何的回归覆盖。
