# 分类复习资料库

## 暂停状态与恢复

本功能暂缓开发，默认关闭前端入口。视频库不显示“复习资料”，直接访问
`/materials` 会替换导航到视频库，历史资料整理任务的“打开”入口同样返回视频库。
关闭时不会挂载资料页、请求资料列表或自动启动整理，也不会删除浏览记录。

后续方向已调整为用户手动从原始资料选取一道完整题目，绑定 DSH 持久对话并生成题目学习记录；
不再以自动拆题、分类题库或考点匹配为目标。新方案和分阶段退出条件见
[资料题目与 DSH 学习记录开发计划](material-question-study-plan.md)。
新“学习资料”已使用独立 `/study-materials` 页面交付本地导入、阅读和手动选题，
详见[学习资料与手动选题](study-materials.md)。它不启用本页所述旧分类资料库。

这是前端可见性开关，不是后端权限控制：既有 API、数据库表、原文件副本、
题目、分类、学习进度与处理记录全部保留。正在运行的任务不会因为隐藏页面被取消；
暂停开发不应启动新的模型调用，也不自动补跑未完成任务。

恢复开发时，在 `frontend/.env.local` 设置 `VITE_ENABLE_MATERIALS=true`，
重新启动 Vite；桌面使用生产页面时，需以该环境变量重新执行 `npm run build`。
变量只有精确为 `true` 时开启，未设置或为 `false` 时关闭；不要将本机配置提交。
恢复默认隐藏时移除变量或改为 `false`，再重启或重新构建。已有资料无需重新导入。

恢复前待办：

- 建立资料集共享标签词表、术语别名及全库归整，当前演示部分题目辅助标签仍为空。
- 完善单题提交与同页多题、跨页区域、共享条件读取和覆盖记录的配合；
  单次提交一个小问不等于语义上只能读取一个来源块，当前读取限制尚需调整。
- 完成 PDF、DOCX 视觉请求的超时、格式与质量抽样验证；真实模型实验只完成部分题目，
  不代表整套资料已整理完成，也不代表分类准确率达标。
- 补全持久化模型版本、token、耗时和失败原因记录；保留人工审核与可恢复删除。
- Codex Plugin 与视频截图匹配仍是后续设计，当前未实现，不因恢复入口自动启用。
- 重新执行后端资料测试、前端关闭与开启状态测试、生产构建，以及隔离浏览器验收。

## 功能边界

视频库旁的“复习资料”入口管理独立资料集。资料可先于视频导入、分类与复习。
一个资料集可关联多个视频文件夹，关联包含子文件夹；视频移动或删除不会删除资料。
本版不执行视频例题匹配，不生成答案或判分。

## 导入与阅读

支持 PDF、JPEG／PNG／WebP、Markdown、DOCX。浏览器上传复制文件到当前库的
`materials/<文档 ID>/`，不移动或修改用户原文件。同内容、不同版本各自保留。
文件哈希只用于完整性校验，不用于筛重。

PDF 使用 pdfplumber 保存文字、词坐标，使用 pypdfium2 保存页面图像。
题目以原文区域呈现；点击“原文定位”查看页面及归一化矩形高亮，跨页题可有多个区域。
清晰扫描页可只保留图像，不强制 OCR。

Markdown 保留顶层段落、列表、表格、代码块及原始行区间；DOCX 以正文顺序读取
段落、表格和内嵌图片，提供内容阅读而非 Word 分页还原。
无法可靠呈现的公式、复杂对象、自动编号、修订、浮动布局或合并表格标记待处理，
用户可以转换成 PDF 或补充清晰题图。Markdown 图片依赖不会自动下载或读取本机路径。
所有阅读视图禁止执行文档 HTML、脚本或自动请求外部图片。

三种视图使用同一组题目：

- 按知识与题型：主题与具体题型两层目录，可跨试卷集中复习。
- 按原始资料：保留卷名、题号及来源顺序，提供整份原文阅读和手动录题。
- 待处理：显示不完整题目、未整理来源、解析失败和缺图等异常。

可以人工修正文字、题图、区域、共享题干、引用与分类，拆分片段或合并同文件片段。
共享题干或前题仍被其他题目引用时，先调整引用或小问归属，再移除、拆分或合并该条目。
独立解析保存为解析条目，不计入题数；由用户手动关联至练习。
只有可独立分离的解析区域折叠，题图本身带答案时仍保留原图。

## 自动整理

用户选择已保存的 AI 连接启动整理，默认选择当前连接。材料仅在执行任务时发送至该服务。
不根据模型名称猜测识图能力；接口拒绝图像输入时任务明确失败，用户更换连接后手动继续。

只有一个 Agent，通过 `read_blocks`、`view_images`、`submit`、`finish` 读取来源并提交。
每次提交最多一个小问或解析，最多附带一个共享情景题干；章节标题（例如“简答题（30 分）”）
只作为原始资料结构，不会被误建成共享题干。
程序控制阶段、调用上限、取消和事务校验，不引入多 Agent、向量数据库或自动去重。
提示词要求原题边界、共享题干、小问、分类、标签和质量说明，不要求解题或固定条件分析。

目录由实际内容生成，优先复用已有分类 ID 和别名。新增资料不会改写用户修改的名称与顺序。
有效题目直接发布并显示“自动整理”，不表示人工确认或分类准确率已获验证。
有关键条件缺失、未找到的前题引用、图像模糊或分类不确定时保留待处理。
每个来源块记录已识别内容、非题目内容或待处理；同页的一部分清晰题可正常保留。

每次提交中题目、目录和来源覆盖状态在同一个 SQLite 事务保存。文字来源必须使用已解析
来源块的 `block_id`，多行块还必须提供块内 `start/end`；PDF 图片使用归一化 `bbox`。
失败或取消保留此前提交，重启不自动调用模型。点击“继续未完成整理”只处理
尚未交代的来源块；已记录的待处理内容交给用户修正，不自动重试收费调用。
传输错误不在资料 Agent 内自动重试；适配器保留原有 JSON 参数兼容处理。

## 持久化与接口

`material_*` 表独立于视频考点和视频题图表。分类和题目使用稳定 ID；
分类关系允许多归属，总题数及学习进度按题目去重。
只改标题、分类或标签保持进度；修改原文区域、修正内容、题图或共享题干后保留旧版本，
新内容从未复习开始。共享题干实质变化也更新小问版本。浏览不会自动标记掌握。
阅读选择、筛选与滚动位置按视频库身份保存在当前浏览器。

文件和题目支持可恢复移除。移除文件隐藏其题目，更新统计并解除失效解析关联；
恢复不会偷偷重建用户已解除的关联。管理目录资源暂不物理清理，保证版本和恢复可读。
资料资源使用相对引用，根目录沿用现有 `library_scope`；应用数据迁移固定库身份和原资源作用域，
迁移后仍可读取，不依赖导入前原文件的位置。

四组 HTTP 接口：

| 路径组 | 主要操作 |
|---|---|
| `/api/material-collections` | 新建、改名、关联文件夹、整理任务、处理记录 |
| `/api/material-documents` | 导入、解析、来源块、原文件、区域裁片、覆盖状态、修正图、移除与恢复 |
| `/api/material-items` | 查询、读取、修正、版本、学习状态、题解关联、拆分合并、移除与恢复 |
| `/api/material-categories` | 目录查询、人工增改、排序、移动与合并 |

内部 `MaterialStore.list_categories`、`find_items`、`read_items` 同时供页面接口和 Agent 使用。
它们返回稳定分类 ID、可批量筛选的题目及原文区域／共享条件，后续匹配无需再建设第二套资料库。

## 验证

后端 `tests/test_materials.py` 使用合成四格式资料、临时 SQLite 和假模型。
前端 `MaterialsPage.test.tsx` 验证分类浏览、原文区域、显式进度、连接选择及安全 Markdown。
接口和假模型测试不代表真实模型分类准确率。

隔离浏览器验收可以运行：

```powershell
python -c "import runpy; runpy.run_path('tests/material_browser_server.py', run_name='__main__')" --root .runtime/materials-qa --port 8879
$env:CLASSROOM_MATERIALS_QA_URL = "http://127.0.0.1:8879"
$env:CLASSROOM_PLAYWRIGHT_MODULE = "<已安装 Playwright 模块目录>"
node tests/materials_paused_browser.cjs
```

默认构建验证入口隐藏、资料页重定向、不请求资料和已有数据保留。
恢复功能验收时先设置 `VITE_ENABLE_MATERIALS=true` 重新构建，再运行
`node tests/materials_browser.cjs`；验收结束应恢复默认关闭并重新构建。

验收服务使用独立配置、合成试卷和独立数据库，使用已构建的前端，默认通过本机 Edge 无头验收。
关闭状态截图与结果保存在 `.runtime/materials-paused-browser/`，
开启状态保存在 `.runtime/materials-browser/`，均不加入发行包。
真实分类效果需用户用自己的资料另行抽样核对。
